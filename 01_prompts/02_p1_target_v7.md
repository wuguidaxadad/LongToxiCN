# P1：中心 Target 发现

## 标注视角

以中国人的语言文化常识和社会语境理解原文，不把境外政治立场或刻板叙事作为默认前提，也不得补充原文之外对中国、中国政府或中国人的负面推断；Target 判断仍只依据原文与下述规则。

## 任务

阅读全文，找出文章真正围绕其展开评价的中心身份群体。

通常只保留一个 Target；只有文章确有两条并列评价主线时，最多保留两个。

## 允许的 Target 类型

- GENDER：性别
- SEXUAL：性取向或性少数
- REGION：地域
- AGE：年龄
- HEALTH：身体或心理健康状态

## 判断规则

应保留：

- 文章持续评价、归责、风险化或讨论处置的身份群体；
- 具体称谓只要明确指向上述身份群体，也可规范化为 Target。

不保留：

- 只在背景中出现的群体；
- 只是事件参与者、比较对象或被顺带提到的群体；
- 与文章主要评价线无关的配角群体；
- 政治组织、职业、阶层、违法行为群体等范围外对象；
- **只以受害者身份出现的群体**：某群体在文中只是被偷、被骗、被引诱、被歧视、被调侃、被伤害的一方，文章的负面评价指向的是另一方。此时 Target 是被评价的那一方（若它是五类身份群体），受害的一方不建。受害方和被评价方都不是五类身份群体时，输出空数组。

**三个测试**（判据以 `../定义/标注规范.md` §3 为准）：

1. **删除测试**：删掉具体事件后，这类人是否仍然存在？仍在 → Target 成立；不在 → 有界行为者集合，不建 Target。唯一例外：原文明确把负面结论外溢到更广的身份群体时，以被外溢到的群体建 Target。
2. **身份依据反事实**：把身份词替换为「任何实施同样行为的人」，原判断是否仍完全成立？仍成立 → 依据是行为而非身份。**这条不删除 Target**，结论写入 `counterfactual_note`，供后续门槛判定使用。
3. **指称还原**：不看名词形式，看实际指称；指代性表达若指回本案已出现的若干具体人物，属有界个案。

## 必须随 Target 一起输出

P2 只看单个语义块，无法从全文推断指称范围，因此每个 Target 必须同时给出：

- `aliases`：允许的原文指称清单；代词只在当前块明确回指这些称谓时有效；
- `scope`：范围说明——纳入哪些身份子群、哪些群体不自动纳入、个案在什么条件下才算作该 Target 的例证。

不要判断文章是否 Hate，不抽取命题，不解释作者立场。

## 输出

只输出 JSON：

{
  "doc_id": "原文档编号",
  "targets": [
    {
      "target_id": "T01",
      "normalized_group": "规范化群体名称",
      "target_type": "GENDER | SEXUAL | REGION | AGE | HEALTH",
      "aliases": ["原文中允许的指称1", "指称2"],
      "scope": "纳入哪些子群、哪些不自动纳入、个案在什么条件下才抽",
      "counterfactual_note": "身份依据反事实的结论；不影响是否建 Target"
    }
  ]
}

没有有效 Target 时，targets 输出空数组。
