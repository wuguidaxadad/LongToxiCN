# P2B：对固定实例判断局部伤害门槛

## 标注视角

以中国人的语言文化常识和社会语境理解原文，不把境外政治立场或刻板叙事作为默认前提，也不得补充原文之外对中国、中国政府或中国人的负面推断；门槛判断仍只依据实例内容与下述规则。

输入含已冻结 Target、当前语义块的全部句元，以及已固定的实例编号和连续原文范围。只逐条判断提供的实例，不新增、不删除、不合并、不拆分、不移动边界。所属块用于理解指代、范围和语义，不把实例外的赞同、反驳或全文结论算到该实例身上。按下面相同的内容门槛判定。不得凭归属者身份或作者认可与否降级。

## 局部身份伤害门槛


每条实例填写 `local_harm_threshold = YES / NO / UNCERTAIN`。

**判断方式：把该实例表达的内容单独抽出来，作为一条直接断言来读**，只问这条断言本身是否已经形成基于身份的群体贬损、集体归责、泛化威胁或不成比例的不利处置。

不问：是谁说的（作者还是引语）、作者是否认可、后文是否限定或反驳、整篇最终是什么标签。这四项全部留给 P3。

**先做 Target 语义角色硬检查。** 先确认负面属性、责任、危险或不利处置是否真正施加在冻结 Target 身上。若实例只说明 Target 遭受轻蔑、歧视、攻击、排斥或污名，而没有呈现一条针对 Target 的具体负面命题，则 Target 是受害者，直接判 `NO`；不得把“有人对 Target 持有偏见”误判成实例本身在贬损 Target。若实例实际呈现或转述了一条针对 Target 的具体负面命题，则继续判断其范围与强度，不因它属于引语或后来被作者反驳而降级。

### 门槛四步（逐条走，不得跳步）

1. **范围**——结论是否超出单一个体、具体案件、特定群聊或有界行为者集合？
2. **身份依据**——这个负面判断是否因 Target 的身份而成立？（反事实检验：换成另一身份的人做同样的事，还会得到同样的评价吗？）
3. **伤害强度**——是否完成群体贬抑、超范围集体归责、普遍威胁化、不成比例排斥四者之一？
4. **限制条件**——是否被具体行为、场景、期限或相称的保护目的限制在门槛以下？

四步全部通过才是 `YES`。**判 `NO` 是正常结果**。不得按预期标签比例决定任何实例的门槛。

### 强度四级

| 级 | 内容 | 填 |
|---|---|---|
| `L0` | 中性事实、政策讨论、个人行为评价、未绑定身份的风险提醒 | `NO` |
| `L1` | 偏见或轻度负面概括：轻度刻板印象、笼统但非侮辱性的差异描述、有依据范围内的群体风险讨论 | `NO` |
| `L2` | 强烈蔑视或羞辱性的群体属性；把社会问题、犯罪或道德失败集体归责于身份群体；把群体构造成需普遍防范的危险；基于身份主张限制、隔离、排斥或差别待遇。**不要求出现行动主张** | `YES` |
| `L3` | 去人化、暴力威胁或正当化、驱逐与剥夺基本权利 | `YES` |

### 四条排除（满足任一即 `NO`，且不标 `C/X/R/A`）

1. 只陈述具体人物、具体事件、统计结果或有界行为者集合，且没有外溢到身份群体；
2. Target 仅作受害者、背景、来源、比较对象或正面对象出现；
3. 结论只依据具体行为成立，而非身份；
4. 身份词仅作骂人比喻或负面参照。

这些实例若确实支持、限定或反对某条 Target 评价，**仍要保留为实例**，只是门槛为 `NO`。

若同一 span 明确把个案或事实上推为身份群体判断，或直接以身份规范评价、限制或排斥个体，则不适用上述排除，继续走门槛四步。

### 行为限定不自动降为 `NO`

把身份与行为共同限定的子群概括为某种稳定缺陷，内容层可以达到门槛。

- **达门槛**：「老是喊着减肥却瘦不下来的女生，这样的女生缺乏自律，不成熟，也没有吸引力」——评价的不是某个人的某次行为，而是一个身份＋行为子群的稳定人格，并据此主张拒绝。
- **未达门槛**：只评价一个明确个体的一次行为，且没有推广到子群。

**「它只是在批评行为」不构成降级理由。** 只有文本**明确否定向身份群体泛化**才算解除身份绑定：

- 真解绑：「这只是几个当事人的行为，不能因此评价女性群体」——明确否定由个案向身份群体推广；
- 范围限定但仍达门槛：「她们只不过是社会人渣，而人渣是不分性别的，也不分职业的」——后半句限制的是向全体女性外推，没有取消前半句对「她们」的群体贬损，仍为 `YES [C]`；
- 假解绑：全程用性别化贬称（软饭男、普信男、油腻、癞蛤蟆）加固，无一句解绑；
- 也不算解绑：把判断抽象到更一般的层级（从「胖女性缺乏自律」抽象成「自制力不够」），只是换了措辞层级，身份绑定仍在。

### 伤害功能

只有 `local_harm_threshold = YES` 时才填，可多选：

- `C` **负面刻画**：对群体品性、能力、状态的负面描写；
- `X` **群体归责**：把某个问题或后果的责任算到群体头上；
- `R` **风险构建**：把群体构造成威胁、危害或侵占；
- `A` **不利处置**：主张对该身份群体施加限制、排斥或剥夺。

**`A` 的方向限定。** `A` 的受动方必须是**冻结 Target 本身**，且内容须是一个**处置主张**（谁提出的不论，引语中的主张同样成立）。两种常见误用：

1. 文本描述的是 Target **对他人**施加的限制或伤害（如“中年男性在饭局上侵扰年轻女性”“上海人欺负外地人”）——受动方不是 Target，应标 `C` 或 `X`，不标 `A`；
2. 文本描述的是 Target **已经遭受**的排斥这一事实，而非主张施加排斥（如“有人被家人赶出家门”“医护人员对其歧视”）——此时 Target 仅作受害者出现，按本节排除条款②不得标达门槛。

针对身份群体或因身份规范而针对个体提出限制、排斥或剥夺时，`A` 才成立；只报告已经发生的处置事实时，`A` 不成立。

`NO` 或 `UNCERTAIN` 时，`harm_functions` 必须为空数组。**引语，或后来被作者反驳的有害命题，只要内容本身达到门槛，局部仍标 `YES`。**

### 已知误判（2026-09-02 复裁结果，输出前逐条自查）

| 误判类型 | 原文 | 正确判定 |
|---|---|---|
| 把同句内的范围限定当成门槛消解 | 「她们只不过是社会人渣，而人渣是不分性别的，也不分职业的」 | `YES [C]`——前半句已达门槛，后半句限的是外推范围，不是取消 |
| 只读了 span 的前半句 | 「就算人家把体重秤压碎好几个也是他自己的事儿，但……中年男人的肥胖对身边人既有生理摧残，也有精神折磨」 | `YES [C]`——后半句是群体断言 |
| 同一篇内标准不一致 | 「男生的强健体魄／女生的柔美身形」＋按性别分配运动项目，与「男孩还是该有男孩该有的样子」 | 两条都是 `YES`——前者更具体，还落实到课程分配 |
| 群体整体定性未识别 | 「他们不过是一群为了个人私利而组织起来的一群社会流氓」 | `YES [C]` |
| 因为是引语而降级 | 男友说「这样的女生缺乏自律，不成熟，也没有吸引力」 | `YES [C, A]`——来源不参与门槛判断 |
| `A` 用反方向 | 「中年男人会劝亲戚小孩儿多喝一杯……逼着小姑娘果汁儿换啤酒」 | `YES [C]`，**不是** `A`——受动方是他人，不是 Target |
