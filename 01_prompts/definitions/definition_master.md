## 1　理论基座

Appraisal 作为**最小分析支架**借用三个顶层视角。

| 视角 | 本项目要回答的问题 | 落在哪些字段 |
|---|---|---|
| **Attitude** | 命题对 Target 形成什么方向、什么内容的评价？ | 命题实例的 `local_harm_threshold`；仅当其为 `YES` 时标 `harm_functions` = C / X / R / A；命题组另记 `canonical_orientation` |
| **Engagement** | 谁提出命题？核心作者如何相对这个声音定位自己？ | `source`、外部声音的 `author_uptake`、`final_author_stance` |
| **Graduation** | 同一评价是否被调强、调弱或收窄？ | `AMPLIFIES / QUALIFIES` |
| **Evaluative prosody** | 同一上位命题轨迹中的局部实例如何跨小句、跨语篇阶段扩散、累积、竞争或反转？ | 命题组及组内实例的 `MAINTAINS / SUPPORTS / AMPLIFIES / QUALIFIES / REJECTS` 序列 |

## 2　研究对象


**数据单位：** 完整的自然中文长文档，且能确定一个核心作者或报道叙述主体。清洗后正文 ≤ 10,000 个非空白中文字符，不设新的长度下限。

**研究的不是**「文章中是否出现过一处仇恨表述」，而是：

> 围绕中心身份群体，文章提出了哪些评价命题；这些命题在全文中如何被维持、支持、增强、限定或拒绝；全文结束时，作者仍承担哪些达到身份伤害门槛的负面命题。

**论文主张：** 单一文档标签不能解释裁决过程；互不连接的 spans 只能保存出现位置，不能表示哪条后文作用于哪条命题。因此：

```text
文中出现负面表达
≠ 核心作者最终承担该表达
≠ 全文结束时仍存在有效身份伤害
```

**核心链条：**

```text
自然中文长文档
→ 人工核验并冻结语义块
→ 身份 Target
→ Target 相关命题实例
→ 实例—规范化命题的链接
→ 命题轨迹与作者最终定位
→ 文档标签（HATE / NON_HATE / BORDERLINE_EXCLUDE）
```

## 3　Target 对象

**定义：** 文章真正围绕其展开评价的**中心身份群体**。

**五个允许维度：**

| 代码 | 含义 |
|---|---|
| `GENDER` | 性别 / 性别身份 |
| `SEXUAL` | 性取向、性少数 |
| `REGION` | 地域 / 国籍 / 籍贯 |
| `AGE` | 年龄 |
| `HEALTH` | 身体或心理健康状态、疾病、残障 |

**应保留：** 文章持续评价、归责、风险化或讨论处置的身份群体；具体称谓只要明确指向上述身份群体，可规范化为 Target；被引用的负面命题所指群体、被作者辩护或反驳污名的群体，仍可能是 Target。

**不保留：** 只在背景中出现的群体；只是事件参与者、比较对象或被顺带提到的群体；与主要评价线无关的配角群体；政治组织、职业、阶层、纯粹由违法行为临时构成的群体等范围外对象。

**身份绑定子群仍可保留：** 若原文把一个行为或组织限定子群稳定地放在五类身份维度之下，并围绕其展开群体评价（如「东北社会人群体」作为东北人的地域身份子群），可以冻结为 Target。此时，针对其行为或组织成员身份本身的批评不自动达到身份伤害门槛；只有结论被归因于身份、外溢到上位身份群体，或把该行为写成身份群体的稳定特征时，才进入身份伤害判断。

**三个测试：**

1. **删除测试**——删掉具体事件后，这类人是否仍然存在？仍在 → 身份群体或身份子群，Target 成立；不在 → 有界行为者集合，**不产生 Target**，记入排除清单并注明理由。例外：原文明确把负面结论外溢到更广身份群体时，以被外溢到的群体建 Target。
2. **身份依据反事实**——把身份词替换为「任何实施同样行为的人」，原判断是否仍完全成立？仍成立 → 依据是行为而非身份
3. **指称还原**——不看名词形式，看实际指称。指代性表达若指回本案已出现的若干具体人物，属有界个案。

> **Target 成立 ≠ 候选达门槛。** Target 由删除测试决定，门槛由身份依据反事实 + 门槛四步（§5）决定。一个 Target 成立、其名下全部候选都不达门槛，是**正常结果**。在 Target 阶段就因反事实删除 Target，会使「负面但非身份仇恨」的边界样本提前消失——那正是数据集必须保留的负例来源。

## 4　仇恨的定义

本项目严格区分**局部命题内容**与**文档级 Hate**：

- **局部命题实例不直接标 `HATE / NON_HATE`。** 标注者只判断：把该实例表达的内容作为一条命题来读，它是否达到身份伤害门槛。这个判断不以核心作者是否认可为前提。
- 每条实例填写 `local_harm_threshold = YES / NO / UNCERTAIN`。**只有 `YES` 才填写 `harm_functions`**，从 `C / X / R / A` 中选择一个或多个；`NO` 与 `UNCERTAIN` 均不强行选择 C/X/R/A。
- 引语、转述或后来被作者反驳的有害命题，只要其命题内容达到门槛，局部仍可标 `local_harm_threshold=YES`；它是否成为文档级 Hate，要到 P3 根据来源、作者最终立场和轨迹终态裁决。
- 正面评价、限定、反驳以及未达门槛的相关材料仍可作为命题实例进入轨迹，但不标 C/X/R/A。
- 既不构成 Target 相关评价，也不支持、增强、限定或反对任何 Target 相关评价的材料不建实例；已抽取但全文核验后确认不服务任何命题组的实例，按 §8.2 退回修正或记为待裁决。
- **文档级 `HATE`：** 至少一条达到最终身份伤害门槛的负面轨迹，被核心作者最终承担，并在全文结束时仍然有效（active）。

**residual active harm 的定义：**

```text
有效身份 Target
∧ canonical_orientation = NEGATIVE
∧ final_author_stance = ENDORSED
∧ final_harm_threshold = YES
∧ trajectory_outcome ≠ CANCELLED
```

**文档标签的推导——对命题组取存在性判断：**

```text
对每个命题组 g 独立计算：
active(g) ⟺ target(g) 有效
          ∧ canonical_orientation(g) = NEGATIVE
          ∧ final_author_stance(g) = ENDORSED
          ∧ final_harm_threshold(g) = YES
          ∧ trajectory_outcome(g) ≠ CANCELLED

HATE               ⟸ ∃g：active(g)，且 g 的上述字段均无 UNCERTAIN
BORDERLINE_EXCLUDE ⟸ 否则，把每个 UNCERTAIN 替换为最不利的可采纳值后 ∃g：active(g)
NON_HATE           ⟸ 其余
```

**命题组之间不做任何合成、加权、抵消或计数。** 文档存在多个 Target 时，跨 Target 同样取存在性判断。组的篇幅、实例条数、跨块范围**不参与**标签推导——它们按 §9.6 记为派生量，只用于分析与复核。

不采用跨组合成的三条理由：

1. 拆组的判据本身就是「终态可能分离」（§8.2）。若组间再做合成运算，拆组即失去意义。
2. 任何跨组合成都要求标注者作一次没有原文依据的整体印象判断，而这正是本数据集要取代的对象。
3. 正负相减已被本节禁止；若允许跨组累积，就必须同时定义跨组抵消，回到同一问题。

不确定只有在**可能改变标签**时才影响标签。文中同时存在反仇恨内容，**不会**自动抵消其他仍然有效的伤害命题；正面内容必须明确限定或反对**同一核心谓词**才会改变那条负面命题。不得用正负命题数量相减推导标签。

## 5　身份伤害门槛


> 对命题内容所做的判断是**身份伤害门槛**：它是否已经形成基于身份的**群体贬损**、**集体归责**、**泛化威胁**或**不成比例的不利处置**。局部判断不考虑核心作者是否认可。

`C / X / R / A` 是**达到门槛之后的伤害功能分类**，不是所有负面内容的宽泛主题标签。只有 `local_harm_threshold=YES` 的命题实例才标一个或多个功能；未达门槛或仍不确定时不标。

**四个伤害功能：**

| 代码 | 名称 | 含义 |
|---|---|---|
| `C` | 负面刻画 | 对群体品性、能力、状态的负面描写 |
| `X` | 群体归责 | 把某个问题或后果的责任算到群体头上 |
| `R` | 风险构建 | 把群体构造成威胁、危害或侵占 |
| `A` | 不利处置 | 主张对该身份群体施加限制、排斥或剥夺 |

**`A` 的方向限定。** `A` 的受动方必须是**冻结 Target 本身**，且内容须是一个**处置主张**（谁提出的不论，引语中的主张同样成立）。两种常见误用：

1. 文本描述的是 Target **对他人**施加的限制或伤害（如“中年男性在饭局上侵扰年轻女性”“上海人欺负外地人”）——受动方不是 Target，应标 `C` 或 `X`，不标 `A`；
2. 文本描述的是 Target **已经遭受**的排斥这一事实，而非主张施加排斥（如“有人被家人赶出家门”“医护人员对其歧视”）——此时 Target 仅作受害者出现，按本节排除条款②不得标达门槛。

针对身份群体或因身份规范而针对个体提出限制、排斥或剥夺时，`A` 才成立；只报告已经发生的处置事实时，`A` 不成立。



**门槛四步** —— 门槛可操作判据：

1. **范围**——结论是否超出单一个体、具体案件、特定群聊或有界行为者集合？
2. **身份依据**——负面判断是否因 Target 的身份而成立？（用 §3 的身份依据反事实）
3. **伤害强度**——是否完成群体贬抑、超范围集体归责、普遍威胁化或不成比例排斥之一？
4. **限制条件**——是否被具体行为、场景、期限或相称的保护目的限制在门槛以下？

判 `NO` 是正常结果。

**局部伤害判断规则：** P2 先按 §7 高召回抽取 Target 相关命题实例，再把每条实例的内容独立送入门槛四步。判断时不问“作者认不认”，只问“这条命题若作为所表达的内容，是否已构成身份伤害”。

**有界事实不自动达门槛。** 只陈述具体人物、具体事件、有界行为者集合、统计结果或 Target 的受害处境时，标 `local_harm_threshold=NO`，不标 C/X/R/A；该实例仍可作为命题组材料保留。只有同一 span 明确把结论上推到身份群体，或直接以身份规范评价、限制或排斥个体时，才继续进入身份伤害门槛判断。

Target 仅作背景、来源、比较对象或正面对象，以及身份词仅作骂人比喻或负面参照时，同样不得标为达到局部门槛。
**门槛强度四级**（`L0`–`L3`。与流程阶段 `P0`–`P3` 无关，不得混用）：

| 级 | 内容 |
|---|---|
| `L0` | 无身份伤害：中性事实、政策讨论、个人行为评价、未绑定身份的风险提醒 |
| `L1` | 偏见或轻度负面概括：轻度刻板印象、笼统但非侮辱性的差异描述、有依据范围内的群体风险讨论。**保留为诊断信号，不直接使文档成为 Hate** |
| `L2` | **达到门槛**：强烈蔑视/羞辱性的群体属性；把社会问题、犯罪或道德失败集体归责于身份群体；把群体构造成需普遍防范的危险；基于身份主张限制、隔离、排斥或差别待遇。不要求出现行动主张 |
| `L3` | 严重身份虐待：去人化、暴力威胁或正当化、驱逐与剥夺基本权利 |

**组内累积达门槛。** 同一命题组内，若单条实例均未单独达到门槛，但组内至少 3 条实例跨至少 2 个语义块持续累积，共同构成稳定的群体低劣／腐败／危险画像，该组 `final_harm_threshold` 可判 `YES`。程序直接从组内链接记录参与实例及块号，不再要求标注者重复抄写。**累积只在组内成立，不跨组累积。**

**低于门槛 vs 达到门槛**对照（X：「该年龄段事故率较高」→ 未达；「社会衰败都是某群体造成的」→ 达到），以及身份绑定规则（「实施诈骗的人应受处罚」针对行为；「某地人天生爱诈骗」泛化到身份；）。

## 6　语义块划分规则

**定义：** 语义块是「围绕同一局部问题或主要输出、能被后续标注者作为一个整体理解的**中等粒度连续文本单元**」。

**文本规范化前置：** NFKC 归一 → 统一简体 → 切分句元 → 一次性编号 `S001…`，*

**新建边界的充分条件：** ①局部问题改变；②主要对象改变**并持续展开**；③得到展开的新结论；④独立的反驳或回应段开始；⑤独立行动或政策段开始。
**单独不足以建边界：** 「换了说话者」「出现了但是」「另起一段」「又提出一条观点」；换行、小标题、日期、编号只是线索不是结论。

**命题 + 紧随的直接回应** 原则上合并为一个 `DISCUSSION` / `REBUTTAL` 块；只有当回应间隔了其他局部问题、开始新章节或长独立论证、引入新对象/事件/核心问题、合并后超软长度上限、或后续已形成可独立调用的新结论时才拆开。**不得为了让每块来源或立场单一而拆分。**

**清单 / 评论拼贴 / 时间线：** 相邻同对象同来源条目按列表模块合并；按「事件 + 相邻评论 + 直接回应」形成讨论块；同一事件的连续发展保留为一块。

**软粒度：** < 60 字通常是碎片；60–100 字须检查能否合并；100–600 字为目标区间；> 600 字须检查新边界；> 800 字原则上拆分。块数上限：50–150 句元的普通文章超过 15 个内容块须逐组检查；150 句元以上超过 25 个内容块须检查是否过切。

**排除内容：** 导航、广告、点赞关注、无关推荐、署名、发布地、版权等纯元数据、无正文的孤立标题、抓取重影。
**人工只允许三种编辑：**

| 操作 | 条件 |
|---|---|
| `MERGE` | 相邻块共同回答同一局部问题，或原命题与紧随的直接回应被误拆 |
| `MOVE` | 边界落在句元内部，或仅因换行产生而两侧仍属同一局部单元 |
| `SPLIT` | 一块中已有两个分别展开的局部问题 |

每次编辑必须记录 `edit_type` 与一句简短理由。不得因为某片段可能有害而调整边界，不得在句元内部切分，也不得为了让每块来源或立场单一而拆分。

**冻结条件：**全部句元按原顺序恰好覆盖一次，无遗漏、无重叠；排除块的功能字段为 `NOT_APPLICABLE`；双标流程的边界编辑已经裁决，或单标流程已完成自查；句元编号没有变化。冻结后 P1–P3 不再修改边界，后续问题必须走补录流程，避免 evidence 锚点失效。

## 7　命题实例抽取规则（P2）


**定位：** 一次只看一个「语义块 × Target」，**隐藏标题和其他语义块**，只做圈选，不判断全文结论。

**单位定义：** 实例**不是**逻辑学意义上的原子命题，也不是一整段完整论证，而是语义块内围绕指定 Target、连续完成**一种局部作用**的最大连续文本。群体判断、个案或成组证据、总结诊断、增强、限定、反驳和应对主张是可区分的局部作用。

**入选测试：**
1. 该 span 如何指向已冻结的 Target；
2. 它对 Target 提出了什么评价，或怎样直接支持、增强、限定或反对一条 Target 评价。


**应当圈选：** 对 Target 的负面或正面评价；明确支撑、举例或重复某条评价的材料；扩大/缩小/改变评价强度和范围的内容；引用、转述、背书、限定或反对某条评价的内容；对 Target 的处境或行为给出因果解释**并明确因此减轻或改变归责**的内容。

**不应圈选：** 与 Target 无关的背景；只说明身份、时间、地点的普通事实；与评价只有主题邻接、无评价作用的材料；只描述现象是否流行、批评是否有效或平台热度变化的材料；只提教育、治理等一般办法而未形成或改变评价的材料；抓取造成的机械重复与无话语作用的冗余文字。

**实例边界六条：**

1. 取同一局部作用覆盖的**最大连续范围**；必要的主语、否定、范围词和引语标记必须保留。为引语标明来源的相邻称谓和转述框架，无论位于引语前还是引语后，都随对应引语保留，不单独成例，也不遗漏；引出下一条发言的框架不并入上一条。实例可以依靠所属语义块和已冻结 Target 解决「他们」「这种心态」等指代，不必为了脱离上下文独立可读而扩大 span。
2. 相邻句子围绕同一 Target、同一主导评价且连续完成同一局部作用时合并；不因为每句能单独概括就逐句建实例。同一个案例内部的背景、行为、经过和结果原则上合并；同一组并列且共同完成一次支持的统计或案例可合并。
3. **局部作用切换时拆分。** 文本从群体判断转入个案／成组证据，或从个案／证据回到群体总结、诊断、限定、反驳或应对主张时，即使各部分服务同一上位命题，也建立不同实例，交给 P3 标记 `SUPPORTS / MAINTAINS / AMPLIFIES / QUALIFIES / REJECTS`。
4. **不按故事情节机械拆分。** 连续案例中的经历、行为和结果共同构成一个完整案例时应合并；但案例前后出现可区分的群体断言、总结、限定或反驳时必须拆分。来源改变、否定词或情节转折本身不是充分条件。**不得预判该实例在 P3 会进入哪个命题组**。
5. 同一原文范围不得重复建实例，实例之间不得重叠。「不是 X，而是 Y」无法自然拆开时保留为一个实例；P3 按 §8.2 的归属程序取第一个成立的动作定组，一条实例只进入一个命题组。
6. 同一命题在后文再次出现，仍在其所在位置再次抽取，交给 P3 归并。

**局部作用测试（拆合判据）：** 先问相邻文字是否都在完成同一件事：同一个群体判断、同一个完整案例、同一组证据，或同一次总结／限定／反驳。是则合并；否则在作用切换处拆分。判断依据是话语作用，不是句子数量，也不是最终 `YES / NO`。


**输出前自检五条：** ①有无把同一完整案例或同一局部作用拆成多个碎片；②有无把群体判断、个案／证据和后续总结跨作用合成一个实例；③有无重复或重叠 span；④有无把标题、设问、来源框架或普通背景独立当成实例；⑤每条能否明确说出它对指定 Target 完成的局部作用，不能则删除。

**P2 的内容标签：** 圈选完成后，每条实例填写 `local_harm_threshold`。只有其为 `YES` 时才填写一个或多个 `harm_functions`（C/X/R/A）；`NO` 或 `UNCERTAIN` 时保持为空。这个判断只针对实例表达的命题内容，不考虑是谁提出、作者是否认可或全文后来是否取消。

判断时临时把该命题当作直接断言，只问内容本身是否构成身份伤害。行为限定不会自动排除身份子群：若文本把“反复减肥失败的胖女性”等身份与行为共同限定的子群，概括为缺乏自律、不成熟、没有吸引力，或据此主张回避、拒绝，局部可标 `YES`；来源和作者承接在 P3 处理。只评价一个明确个体的一次行为且没有推广到身份子群时，标 `NO`。

**P2 不填：** 来源、作者立场、上下文依赖、实例—命题组关系和文档标签。上述内容必须在 P3 阅读全文后判断。

## 8　命题归并与轨迹关系（P3）


### 8.1　上位命题组就是命题轨迹

上位命题是组内实例共同处理的**Target-bound 潜在伤害判断**。命题组记录这条判断从出现到全文结束的生命周期，而不是按主题收集文章中的所有独立命题。它不是文章主题，不是组内各种声音的共识，也不是核心作者的最终结论。赞同、支持、限定和反对该命题的声音可以进入同一组；作者最终是否承担该命题，另由 `final_author_stance` 裁决。

原因解释、教育建议、正面材料或制度批评，如果会改变该潜在伤害判断的**身份依据、强度、范围、可改变性、作者承担或最终门槛**，仍进入同一命题组。不得仅因它们表面上能改写成另一条句子，就另建“原因组”“建议组”或“正面组”。例如，前文称某群体“普遍柔弱”，后文说明这种状态由学校环境造成且可以改善；后文不是与前文无关的教育命题，而是在把“身份固有缺陷”限定为“情境造成、可以改变的状态”。

上位命题写成一条完整、可判断真假的句子：

```text
Target + 核心评价/归责/风险/处置 + 必要的范围或条件
```

提取时遵守四条规则：

1. **最具体：**保留原文反复处理的核心谓词；能写“缺乏自律”，便不写成“存在问题”。
2. **不新增：**Target、核心谓词、因果关系和必要条件均须有原文依据；删除人名、时间、单个案例和来源外壳。
3. **可覆盖：**每个组内实例都必须能直接维持、支持、增强、限定或拒绝该命题。
4. **可区分：**若只能用“作者对 Target 持负面态度”等空泛表述才能覆盖多个实例，必须拆组。

「最具体」与「可覆盖」发生冲突时，以 §8.2 的**核心判断与共同命运测试**裁决，不凭语感取舍。

优先采用标题、小标题、总结句或反复出现的判断作为上位命题；没有可直接复用的句子时，只允许作满足上述规则的最小规范化改写。命题组本身就是命题轨迹，不再建立“具体轨迹之上的第二层上位组”。

每组填写：`canonical_proposition`（上位命题）与 `canonical_orientation`（`NEGATIVE / POSITIVE`）。命题组不再人工填写单一 `harm_function`；C/X/R/A 保存在达到局部门槛的命题实例上。命题组仍须在全文裁决后填写 `final_harm_threshold`，因为增强、限定、拒绝或组内累积可能使终态门槛不同于任何单条实例。

### 8.2　实例的归属：一条实例进哪个组

**一条实例只进入一个命题组。** 不建立多重链接。

**先定组，再挂实例。** 不得从实例出发做主题聚类。先从原文可直接复用的判断句——标题、小标题、总结句、反复出现的断言——立候选组，再把实例挂上去。组的身份是**一个核心谓词及其归责结构**，不是一个话题。

**归属程序**（依次判断，第一个成立即定）：

1. 该实例是否在**改变另一条已有命题的成立**（否定、削弱、收窄、附加条件）？→ 归入**被改变的那条**命题所在的组，标 `QUALIFIES` / `REJECTS`，**不另立组**。
2. 该实例是否在**为某条已有命题提供例子、理由、数据、引用或重述**？→ 归入该组，标 `SUPPORTS` / `MAINTAINS` / `AMPLIFIES`。
3. 该实例是否**提出一条自身可独立判断真假、且原文单独展开过的评价**？→ **提出候选组**。候选组能否最终单列，一律回到拆合判据（触发 A／否决条件／触发 B）裁决；两者均不成立时并入最相关的已有组。单实例组合法，但必须能写出满足 §8.1「最具体」「不新增」的上位命题。
4. 以上皆否 → `status = UNRESOLVED`，交盲裁。**不得为了安置一条实例而建立空泛的组。**

第 1 步优先于第 2、3 步。制度性解释、缓和材料与外部反驳最常被误当作新命题——它们不是新命题，是对既有命题的操作。

**谁说了算：组的存在与否由拆合判据决定，归属程序只负责把实例挂上去。** 归属程序第 3 步只能*提出*候选组，不能*确立*组（2026-09-03 修订）。

**一条实例同时作用于多个组时的归属（2026-09-03 定）**

一条限定或反驳，其射程可能只覆盖一个组，也可能同时覆盖多个组。**同一 Target 不等于限定自动作用于它名下的全部命题**——"这些问题不能全怪个人，也有环境原因"可能削弱个人归责，却没有否定前文描述的行为。射程必须逐组判断，不得程序化地给每组都记一次 `QUALIFIES`。

规则（不新增字段、不复制 span）：

1. **一条实例仍然只归一个组。**
2. 优先归入**它明确回应的那个组**；
3. 若它同等明确地回应多个组，归入**原文中最近被回应的那个组**；
4. 在 `links[].explanation` 中写明**它同时作用于哪些其他组、作用是什么**；被波及的组在其 `explanation` 中回引该实例编号；
5. **全文终态裁决不得忽略这些跨组作用。**

例：P01「这个群体懒惰」、P02「这个群体不诚实」，后文出现"所谓懒惰、不诚实，都是对他们的污蔑"。该实例按第 3 条归入较近的 P02 标 `REJECTS`，同时在说明中记录它也反驳 P01；**若作者接受这段反驳，P01 就不能当作从未被反驳来裁决终态。**

**与触发 A 不冲突。** 触发 A 管的是"只反驳甲、不反驳乙"这种**不对称**情形；同时反驳甲乙的材料，本身不在甲乙之间触发 A。

**代价必须写明。** 采用本规则后，**不能仅凭组内关系列表自动推出全部终态**，仍须结合全文与说明栏核验。若将来要求所有语义作用都能被程序完整评测，就必须另行记录这些跨组作用——不能既省掉它们，又宣称关系标注是完整的。

**唯一归属是记录方式，不意味着语义作用只能有一个对象。** "放进最近的组"是整理办法；"假装没看见它还反驳了其他组"不行——那会让本该被否定的判断继续算作残余伤害，直接改变文档标签。


**先做伤害候选测试，再做拆合测试。** 若一个实例实际改变已有潜在伤害判断的身份依据、范围、强度、可改变性或最终门槛，先按第 1 步归入该组；不能因为它能单独改写成一句建议就机械拆组。

> **单一权威源。** 本节是完整拆合规则的权威源，并与 `../提示词/P3_全文命题轨迹.md` 保持逐字一致。`标注规范.md` 是面向标注者的简明等价表述，不再复制全部论证和例外。改动后用 `_定义/检查一致性.py` 校验。

**拆合判据——默认合并，拆分需要理由。**

默认：同一 Target 下的实例进入同一个命题组。**合并不需要理由，拆分需要**，并必须在 `threshold_note` 中写明依据。

**判断顺序：触发 A → 否决条件 → 触发 B。** 顺序不可颠倒。

**触发 A——专属限定（最高优先，直接关系文档标签）**

存在实例 X，对候选组甲构成 `QUALIFIES` 或 `REJECTS`，而对候选组乙**不产生任何限定作用** → 甲乙拆组。

必须写出三样：X 的编号、它限定甲的原文片段、为什么它不作用于乙。三样缺一，触发不成立。

这一条管的是假阴性——限定的效力漏到它管不着的判断上，会使整组被误判为已被取消。HTP-0004 即属此类：体育课“三化”与安全至上环境的解释只限定“男性青少年体质柔弱”，若与“男孩该有男孩的样子”同组，会使全文被误判为 NON_HATE。

**触发 A 优先于否决条件。** 即使两个谓词在原文中被多次同时断言，只要后文实际上只限定或反驳其中一个，仍须拆组；否则该限定的效力会漏到它管不着的判断上，等于把否决条件变成新的假阴性来源。

**否决条件（触发 A 不成立时适用，压过触发 B）**

若有 **≥2 条**实例，其 span 内以**断言形式**同时提出两个候选组的核心谓词 → **禁止拆分**。

判断“是否断言”的检验：把该句单独抽出，它是否把该谓词作为**已成立的事实**提出？建议、期许、被引述的他人说法、作为争议标签提到的表述，都不算断言。要求 ≥2 条，是为了不让分组取决于 P2 阶段单条 span 的划界方式。

例：HTP-0099 的“一、逐步堕落，永堕地狱……如果你管不住自己，那只能说自作自受”把堕落与归责写在同一句内，且同类句子有三处 → 不得把“主动堕落”与“自作自受”拆成两组。

**传递性（有条件，不可无条件适用）。** 否决条件按候选组两两判断。甲与乙触发否决、甲与丙也触发否决，而乙与丙之间没有直接双断言时，三者是否同组，须**同时**满足三条：

1. 甲乙丙能被**同一条上位命题直接覆盖**，不需要借助空泛概括；
2. 原文**反复把它们作为同一条发展线共同呈现**，而非各自出现在互不相关的位置；
3. 三者**没有各自独立的限定、反驳或不同终态**（即触发 A 对其中任一对均不成立）。

三条缺一，不得靠传递性合并；此时把无法直接连接的那条单列，并在 `threshold_note` 中说明。

设此限制是为了**防止链式吞并**——若允许无条件传递，文章中大量互不相干的判断会经由中间命题被逐级连接，最终塞进同一个组。

**触发 B——原文显式结构**

三个条件同时满足才成立：

1. 两部分各自被原文的**显式结构标记**分隔（小标题、编号序号、“第一/第二”“一方面/另一方面”）；
2. 两部分在原文中各自**连续**，不得交错；
3. 各自有 **≥2 条**实例。

例：HTP-0020 的“一、地铁上的汗臭大叔／二、饭桌上的劝酒领导／三、住一个小区的二伯／四、微博上的中年直男癌”三条全部满足 → 拆组成立。
反例：HTP-0008B 的十条编号中，第 5、6、8 条与其余各条交错分布，第 2 条不满足 → 不得拆组。

**禁止的拆分理由**

话题不同、`C/X/R/A` 功能不同、来源、位置、措辞、强度、范围、赞同或反对方向，以及**标注者自己对终态的判断**（终态是拆组的结果，不能反过来作为拆组的理由）。

以下两条旧判据自 2026-09-02 起废止，不得再作为拆组依据：①“它们是否都在回答同一个可以用是/否裁决的核心判断”——该问题本身即争议所在，且未规定抽象层级，向上抽象一级即为一条、向下降一级即为两条；②“全文结束时是否可能具有不同的作者立场、门槛或结局”——终态由标注者判定，用它论证拆分构成循环。

**形式检验（双向）**

上位命题必须是一条可裁决判断，**只含一个核心谓词**，并且必须**覆盖组内全部成员实例**。两个方向都要查：

- 写成“外貌、观念、性别态度和公共行为都有问题”一类并列清单 → 合并范围过宽，回到触发 A/B 重新检查；
- 缩到覆盖不了组内成员 → 同样不合格。例：HTP-0044 的上位命题若写成“男同性恋者普遍多性伴、性关系混乱”，就盖不住组内的异性婚姻与感染后报复两类实例；正确写法是把多性伴作为**机制**、把其余作为该机制的**风险展开**，合成一条轨迹。

**并列的合法与不合法。** 顿号本身不是问题：用于同一核心谓词下的**同义并列**（“寄生、不劳而获、欺软怕硬的当代阿Q式人格”）或**原因并列**（“因肥胖、秃顶和不修边幅而外表油腻”）是允许的。不允许的是**几个可独立裁决的谓词并列**（“吹嘘、为难服务员、强行劝酒并侵扰年轻女性”——四者各自可判真假，没有统一核心）。自查方法：能否用“核心谓词＋机制／展开”重写？能，说明是合法并列；不能，说明合并范围过宽。

**组数指引**

单个 Target 通常 1–3 组。超过 3 组时，须在 `uncertainties` 中逐组写明其触发依据（A 或 B、依据实例编号）。

**保留的规则**：方向本身不拆组，反对同一命题的实例仍留在组内标 `REJECTS`；无法自然拆开的复合表达（“不是 X，而是 Y”）取第一个成立的动作定组。

**风险不对称——归属是裁决的一部分，不是整理工作。** 把反驳错误归入 A 组 → 程序建议 `CANCELLED` → 假阴性；把支持材料错误并入他组 → 未达门槛的内容被抬过门槛 → 假阳性。

### 8.3　实例—上位命题关系

| 关系 | 判断标准 |
|---|---|
| `MAINTAINS` | 近义重述或继续维持，没有新增理由，也没有改变强度或范围 |
| `SUPPORTS` | 增加新案例、事实、数据、引用或理由，但不改变命题内容 |
| `AMPLIFIES` | 提高强度、扩大范围，或把类别边界说得更绝对 |
| `QUALIFIES` | 保留核心谓词，但降低强度、缩小范围、增加限制条件，或把身份固有归因改为情境原因、可改变状态 |
| `REJECTS` | 否定核心谓词、群体归因或命题成立的关键理由 |

按以下顺序选择单一主关系：

1. 否定核心谓词、群体归因或关键理由 → `REJECTS`；
2. 保留核心谓词，但调弱、收窄、附加条件，或将原因从身份本身转向具体环境并明确其可改变 → `QUALIFIES`；
3. 明确调强、扩大或绝对化 → `AMPLIFIES`；
4. 新增案例、事实或理由 → `SUPPORTS`；
5. 仅重述或延续 → `MAINTAINS`。

若同一实例既提供证据又明确改变强度或范围，优先标 `AMPLIFIES`；只有证据增加而命题内容不变时才标 `SUPPORTS`。区分 `QUALIFIES` 与 `REJECTS` 时检查核心谓词：核心谓词仍针对同一 Target 成立，只是更弱或更窄，为 `QUALIFIES`；核心谓词、身份归因或群体层判断不再成立，为 `REJECTS`。

建设性建议不会自动抵消负面命题。只有当建议或原因解释明确改变了负面命题的身份归因、适用范围、强度或可改变性时，才标 `QUALIFIES`；若它仍把群体视为固有缺陷并要求矫正，则应标 `MAINTAINS`、`SUPPORTS` 或 `AMPLIFIES`。

**每条实例直接相对于上位命题选择关系；本项目不标注命题组之间的关系。组内第一条实例同样填写关系——「文中最早位置」由程序按 evidence 顺序派生，不设 `INTRODUCES`。**


### 8.4　来源与作者定位

- `source`：`AUTHOR` 核心作者或主叙述者 / `OTHER` 引语、转述者、被报道者等外部声音 / `UNCLEAR`。
- 当 `source=OTHER` 时，另填 `author_uptake`：`ADOPTED / PRESENTED / OPPOSED / UNCLEAR`。

`relation` 只说明当前实例怎样处理上位命题，不等于作者立场。例如，外部专家反驳命题而作者只作中性转述时，应标 `relation=REJECTS`、`source=OTHER`、`author_uptake=PRESENTED`，不能据此推断作者也拒绝该命题。

**来源按命题声音判断，不按句子的表面书写者判断。** 即使标题、导语或记者自撰概括句由核心作者写成，只要其中保留“某人称／某组织认为／专家表示”等明确归属框架，被归属的命题仍为 `source=OTHER`。标题、导语、篇首位置、醒目编排、反复引述或全文未反驳，只能证明作者选择呈现该声音，**不能单独证明作者认可它**。

`author_uptake=ADOPTED` 必须有正面承接证据：作者去除归属框架后以自己的声音把该命题重述为事实或结论、明确表示赞同，或把它作为前提继续推理、支持或增强。只有引述、转述、概括其立场、交代争议来源、顺序编排或未加反驳时，填 `PRESENTED`。作者明确否定或批评该命题时填 `OPPOSED`；证据不足以区分时填 `UNCLEAR`。

### 8.5　轨迹终态

- `final_author_stance`：`ENDORSED` / `DISTANCED` / `REJECTED` / `UNCERTAIN`
- `trajectory_outcome`：`MAINTAINED` / `STRENGTHENED` / `NARROWED` / `CANCELLED` / `UNCERTAIN`（**由程序按关系序列建议，人工只确认或修改**）
- `final_harm_threshold`：负面填 `YES` / `NO` / `UNCERTAIN`；正面为 null

**终态与门槛分开裁定。** `trajectory_outcome` 判断核心命题经过全文处理后是否维持、增强、收窄或取消；`final_harm_threshold` 对最终保留的命题内容重新执行 §5 的门槛四步。`NARROWED` 可以对应 `YES`，也可以对应 `NO`：范围或强度收窄后仍构成身份伤害，填 `YES`；仅剩门槛以下的内容，填 `NO`。未被取消不等于仍达门槛，出现限定也不等于降到门槛以下。必须指出原文实际改变了什么，不得只凭自省、善意、建议或环境解释判 `NO`。P2 的局部门槛保持冻结。

## 9　标注台字段总表

本节只回答“每一步填什么”。字段含义和判断规则分别见 §3、§5、§7、§8，不在这里重复展开。

### 9.1　语义块边界核验

人工只调整并冻结语义块的起止位置：`MERGE / MOVE / SPLIT`。本步不标 Target、命题或仇恨属性。

### 9.2　核心作者

| 字段 | 要求 |
|---|---|
| `focal_author_type` | **必填**：个人作者／主叙述者，或媒体／机构叙述主体 |
| `rationale` | 选填；仅在转载、多人材料或叙述主体不清时填写 |

该字段只确定后续 `AUTHOR` 的参照对象，本身不参与文档标签推导。

### 9.3　Target

| 字段 | 要求 |
|---|---|
| `target_id` | 程序生成 |
| `normalized_group` | **必填**：简短的规范化群体名称 |
| `primary_dimension` | **必填**：`GENDER / SEXUAL / REGION / AGE / HEALTH / NEEDS_REVIEW` |
| `identity_binding_evidence` | **必填**：确认该群体身份的连续原文 |
| `boundary_note` | 选填；仅在 Target 边界有歧义时填写 |
| `targets.uncertainties` | 选填；记录仍需裁决的问题 |

全文没有范围内 Target 时，勾选 `no_target_confirmed`，不建立 Target。

### 9.4　命题实例

| 字段 | 要求 |
|---|---|
| `occurrence_id` | 程序生成 |
| `block_id` / `target_id` | 由当前“语义块 × Target”任务自动确定 |
| `evidence` | **必填**：当前语义块内唯一一个连续原文 span |
| `normalized_proposition` | 选填：原文过长时用一句话概括，不替代原文 span |
| `local_harm_threshold` | **必填**：`YES / NO / UNCERTAIN`；只判断命题内容 |
| `harm_functions` | 条件必填：仅当门槛为 `YES` 时选择一个或多个 `C / X / R / A` |

本步不填来源、作者立场、组内关系或文档标签。

### 9.5　命题组与命题轨迹

**建立命题组：**

| 字段 | 要求 |
|---|---|
| `proposition_id` | 程序生成 |
| `target_id` | **必填**：该组对应的 Target |
| `canonical_proposition` | **必填**：组内实例共同处理的上位命题 |
| `canonical_orientation` | **必填**：`NEGATIVE / POSITIVE` |

**每条组内实例：**

| 字段 | 要求 |
|---|---|
| `proposition_id` | 选择实例进入哪个命题组；一条实例只进入一个组 |
| `relation` | **必填**：`MAINTAINS / SUPPORTS / AMPLIFIES / QUALIFIES / REJECTS` |
| `source` | **必填**：`AUTHOR / OTHER / UNCLEAR` |
| `author_uptake` | 条件必填：`source=OTHER` 时选择 `ADOPTED / PRESENTED / OPPOSED / UNCLEAR` |

**每个命题组的最终裁决：**

| 字段 | 要求 |
|---|---|
| `final_author_stance` | **必填**：`ENDORSED / DISTANCED / REJECTED / UNCERTAIN` |
| `trajectory_outcome` | **必填**：程序建议，人工确认 `MAINTAINED / STRENGTHENED / NARROWED / CANCELLED / UNCERTAIN` |
| `final_harm_threshold` | 条件必填：负面命题填 `YES / NO / UNCERTAIN`；正面命题填 `null` |
| `threshold_note` | **必填**（2026-09-02 起）：逐条列出组内达到局部门槛的实例编号与所跨语义块；依靠组内累积时按 §5 三条硬约束逐条列出；本组若为拆分所得，写明触发依据 |
| `explanation` | **必填**（2026-09-02 起）：该轨迹如何被提出、如何被支持或限定、终态为何如此 |

**每条实例的归属记录（`occurrence_assignments`）：**

| 字段 | 要求 |
|---|---|
| `occurrence_ref` | 格式 `块号:Target号:实例号`，与 P2 输出一一对应，每条实例出现且只出现一次 |
| `status` | **必填**：`USED` / `UNRESOLVED`；后者在 `reason` 写明原因 |
| `links` | **恒为长度 1 的数组**：一条实例只进一个命题组 |
| `links[].explanation` | **必填**（2026-09-02 起）：该实例对上位命题完成了什么动作 |

### 9.6　最终核验与程序输出

人工不填写文档标签。程序按 §4 自动生成 `HATE / NON_HATE / BORDERLINE_EXCLUDE`，并计算：

- 每组实例数、覆盖块数和首尾位置；
- 五种关系的数量；
- 每组是否为 `active harm`；
- 文档最终标签。

**未定义字段清单（2026-09-02 标记，待补定义）。** 工作台的 `resolution.document_decision` 与 `resolution.context_effects` 中，以下字段在本定义体系内没有任何定义，既未规定取值含义，也未规定由谁填写：

| 字段 | 现状 |
|---|---|
| `document_decision.active_harm_ids` | 按 §4 可推导（NEGATIVE + ENDORSED + `final_harm_threshold=YES` + `trajectory_outcome≠CANCELLED`），但未写入本表 |
| `document_decision.potential_active_harm_ids` | 无定义。当前实践：达门槛但因作者立场非 ENDORSED 或终态为 UNCERTAIN 而未计入 active 的组 |
| `document_decision.context_dependency` | 无定义。数据中出现 `CONTEXT_RESOLVED` / `LOCALIZED` 两值 |
| `document_decision.counter_hate_present` | 无定义。当前实践：全文是否含明确反对针对该 Target 的歧视、污名或排斥的材料 |
| `document_decision.composition_only` | 无定义。当前数据全为 `false` |
| `document_decision.rationale` | 无定义。当前实践：文档标签的理由说明 |
| `context_effects` 的四个布尔 | 无定义。当前实践：记录全文语境相对局部判断改变了来源、作者立场、范围或门槛中的哪些 |

在补上定义之前，这些字段**不得作为 Gold 的一部分参与评估**，也不得写入 P2/P3 提示词要求模型输出。

最终阶段只检查缺项、未分组实例和不确定项，然后提交。阶段耗时、现场解释和界面问题属于 Pilot 流程记录，不是 Gold 标签字段。

## 10　文档准入规则


**流程：** 原始候选 → 体裁排除 → 资格预审 → 文本规范化与句元编号 → P0 模型分块 → 人工改边界与裁决 → 冻结语义块。

任何准入步骤都不得使用旧 Hate 标签、旧 Target 或模型的有害性预测决定文章是否进入。

**体裁排除只有两类：** ①整页评论区（正文后附大量互不组织的用户评论，反复出现用户名/时间/"发表评论于"等页面结构）；②小说与虚构章节（章节、连载目录、本章字数等信号）。

满足：** 主要正文语义基本完整；能确定一个核心作者或报道叙述主体；不是多篇无关文章或评论串的机械拼接；导航/广告/版权等噪声可清除且清除后正文完整；含可供命题标注的连续自然语言。

**排除状态：**

| 状态 | 使用条件 |
|---|---|
| `DATA_QUALITY_EXCLUDE` | 正文残缺、乱码严重或噪声压倒正文 |
| `MULTI_DOCUMENT_EXCLUDE` | 多篇无关正文拼接，无法恢复单一文档边界 |
| `FOCAL_AUTHOR_EXCLUDE` | 无统一组织者的评论或材料拼贴 |
| `NOT_ARTICLE_EXCLUDE` | 只有目录、链接、标题或数据表 |
| `OUT_OF_SCOPE_EXCLUDE` | 主要负面对象必须依靠民族/种族维度才成立（见 §3） |
| `HUMAN_REVIEW` | 仅凭当前输入无法可靠决定 |

**不是排除理由：** 文风、观点、政治立场、是否负面、是否有害；报道中有多个受访者、正文含多个章节或案例。

**范围外维度：** v1 只覆盖 §3 的五类 Target。民族与种族身份不得改标为 `REGION`。文章的主要负面对象若必须依靠民族或种族维度才能成立，整篇记 `OUT_OF_SCOPE_EXCLUDE`，不得走完流程后推导成 `NON_HATE`。同一文章若另有范围内 Target 承载独立命题，则保留文章，只把范围外群体记入排除清单。

**长度与规范化：** 清洗后 ≤ 10,000 非空白中文字符；NFKC + 简体；句元一次性编号后不得重排。

## 11　人工标注流程与工作台

### 11.1　完整流程

```text
Raw 准入语料
→ P0 模型生成分块副本
→ 人工核验并冻结语义块
→ 确定默认叙述声音类型，作为后续 AUTHOR 的判断参照
→ P1 通读全文确定 Target 并冻结
→ P2 每次只看一个「语义块 × Target」，抽取命题实例；判断局部身份伤害门槛，只有达门槛实例标 C/X/R/A
→ P3 阅读全文，归并命题轨迹、裁决作者关系与残余状态
→ 程序推导 HATE / NON_HATE / BORDERLINE_EXCLUDE
```

### 11.2　强制复核触发

满足以下任一条件的文档进入强制复核队列。复核者须重新核对指定字段，但**不得直接改写文档标签**：

| 触发条件 | 复核对象 |
|---|---|
| 全文唯一的 active 组同时满足 `occurrence_count = 1`、`block_span = 1`、组内无 `SUPPORTS`／`AMPLIFIES` | 该组的 `final_author_stance` 与 `final_harm_threshold` |
| 任一组的 `final_harm_threshold` 由组内累积判 `YES` | 组内参与累积的实例数量和覆盖块数是否满足 §5 的硬约束 |
| 存在 `status = UNRESOLVED` 的实例 | 该实例的归属 |

复核阶段把全文所有命题组铺成一张表并列显示：上位命题、`canonical_orientation`、成员实例的 `local_harm_threshold / harm_functions`、三个终态字段、§9.6 派生量与 `active` 标记。复核者只能**将指定字段打回重判**或**记录 dissent**；文档标签仍由字段重新推导，不得整体改写。
