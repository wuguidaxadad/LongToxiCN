# 长文本仇恨标注手册

> 本手册只说标注时实际怎么做。完整特殊情况和标签推导以《定义总表》为准。

## 1. 任务与流程

我们要保留两层信息：

1. **命题实例**：文章局部对中心 Target 说了什么；
2. **命题组**：这些局部表达围绕哪条上位判断发展，最后被维持、增强、限定还是拒绝。

```text
核对语义块 → 确定 Target → 圈选命题实例 → 建立命题组 → 判断终态
```

### 语义块与 Target

- 语义块由模型先分，人工只合并、拆分或移动明显错误的边界。分块时不判断仇恨。
- Target 是文章持续评价的中心身份群体。通常一个；确有两条并列主线时最多两个。
- 只使用 `GENDER / SEXUAL / REGION / AGE / HEALTH`。
- Target 成立不代表文章构成仇恨。

---

## 2. P2：抽取命题实例

### 2.1 什么是命题实例

命题实例是语义块内一次完整的 **Target 相关评价动作**，包括：

- 对 Target 的正面或负面判断；
- 支持该判断的案例、理由或数据；
- 对该判断的增强、限定或反驳；
- 明确改变对 Target 归责的原因解释。

它不是逻辑学中的最小原子命题。相邻句子共同完成一次评价、一个完整案例或一组证据时，应作为一个实例。

### 2.2 不抽取什么

- 与 Target 无关的背景；
- 只说明人物身份、时间、地点的材料；
- 不支持、增强、限定或反对任何 Target 评价的普通事实；
- 单纯的热度、传播史、网页重复和机械残留；
- 不改变任何 Target 评价的一般性建议。

### 2.3 span 怎么拆

**先问：相邻文字是否在完成同一次局部作用？**

合并：

- 同一 Target、同一主导判断连续展开；
- 一个案例的背景、行为、经过和结果共同完成一次举例；
- 一组并列数据或案例共同支持同一判断；
- 标题或设问只服务于紧随其后的评价；为引语标明来源的相邻称谓和转述框架，无论在引语前还是引语后，都随对应引语保留，不单独成例，也不遗漏。引出下一条发言的框架不并入上一条。

拆分：

- 群体判断 ↔ 个案/数据发生切换；
- 个案/证据 → 群体总结发生切换；
- 提出/支持 → 限定、反驳或应对主张发生切换；
- 说话者和核心判断同时发生实质变化。

不按故事情节、句号或否定词机械拆分。每条 span 取同一局部作用下的**最大连续范围**，不跨语义块，不重叠，不用省略号拼接不连续文字。

### 2.4 P2 字段

| 字段 | 要求 |
|---|---|
| 连续原文 span | 必填 |
| 命题简述 | 可选；忠实保留原文量词、条件和范围 |
| 局部伤害门槛 | `YES / NO / UNCERTAIN` |
| 伤害功能 | 只有门槛为 `YES` 时选 `C / X / R / A`，可多选 |

P2 只判断这条命题的内容，不考虑谁说的、作者是否认可、后文是否反驳。

### 2.5 局部伤害门槛

依次问：

1. **范围**：是否超出单一人物、具体案件或有界行为者集合？
2. **身份依据**：换成“任何实施同样行为的人”后，判断是否仍完全成立？
3. **强度**：是否已形成群体贬抑、超范围集体归责、普遍威胁化或不成比例排斥？
4. **限制**：是否被具体行为、场景、期限或相称保护目的限制在门槛以下？

只讲具体个案、有界事实、统计结果或 Target 的受害处境，通常为 `NO`，但仍可作为组内材料。

`YES` 后再选：

- `C`：群体负面刻画；
- `X`：群体归责；
- `R`：群体风险化或威胁化；
- `A`：针对 Target 本身的不利处置、排斥或限制主张。

`A` 的受动方必须是 Target。Target 伤害他人，或 Target 已经遭遇排斥的事实报道，都不因此标 `A`。

## 3. P3：建立命题组

### 3.1 什么是命题组

命题组是一条 **Target-bound 上位判断的发展轨迹**。组内可以同时有提出、支持、增强、限定和反驳它的声音。

命题组不是话题聚类。原因解释、教育建议、正面材料或制度批评，如果会改变某条上位判断的身份依据、强度、范围、可改变性、作者承担或最终门槛，就进入该组，不另建“原因组”或“建议组”。

### 3.2 实例怎么归组

按顺序问：

1. 它是否在否定、削弱、收窄或附加条件给已有判断？是 → 进入被改变的组；
2. 它是否在为已有判断提供重述、案例、理由或增强？是 → 进入该组；
3. 它是否提出原文单独展开的新判断？是 → 只能提出候选组，再按下一节判断能否单列；
4. 都不是 → `UNRESOLVED`，交裁决。

一条实例只进入一个组。如果它同时作用于多个组，优先进入明确回应的组；同样明确时进入原文中最近的组，并在“作用说明”中记录其他作用。

### 3.3 命题组拆合

**默认合并，拆分需要证据。顺序必须是：规则 A → 合并否决条件 → 规则 B。**

#### 规则 A：专属限定

存在实例 X，它对候选判断甲构成 `QUALIFIES` 或 `REJECTS`，但对候选判断乙没有任何限定作用 → 甲乙必须拆组。

必须写明 X 的编号、限定/反驳甲的原文，以及它为什么不作用于乙。规则 A 优先级最高。

#### 合并否决条件

规则 A 不成立时，如果至少有 **2 条实例**，每条 span 都以断言形式同时提出两个候选组的核心谓词 → **禁止拆分**。

“断言”指把谓词当作已成立的事实提出。建议、期许、被引述的他人说法或争议标签都不算断言。不得用无条件链式传递把互不相关的判断吞进一组。

#### 规则 B：原文显式结构

三条同时满足才可拆组：

1. 原文用小标题、编号、“第一/第二”或“一方面/另一方面”显式分隔；
2. 两部分各自连续，不交错；
3. 两部分各至少有 2 条实例。

话题、C/X/R/A、来源、位置、措辞、强度、范围、赞同/反对方向和预判终态，都不能单独作为拆组理由。

### 3.4 上位命题怎么写

- 优先用原文标题、小标题、总结句或反复出现的判断；
- 没有可直接复用的原句时，只作最小改写；
- 必须指向冻结 Target，有一个清楚核心谓词，并覆盖组内全部实例；
- 不能写成“该群体在多方面存在问题”这种空泛包装。

单个 Target 通常 1–3 组。超过 3 组时，逐组记录规则 A 或 B 的证据。

### 3.5 组内字段与五种关系

每条实例填：

| 字段 | 取值 |
|---|---|
| 来源 | `AUTHOR / OTHER / UNCLEAR` |
| 作者处理 | 来源为 `OTHER` 时填 `ADOPTED / PRESENTED / OPPOSED / UNCLEAR` |
| 相对上位命题的关系 | `MAINTAINS / SUPPORTS / AMPLIFIES / QUALIFIES / REJECTS` |
| 作用说明 | 简要说明理由；有跨组作用时必填 |

| 关系 | 判断标准 |
|---|---|
| `MAINTAINS` | 近义重述或继续维持，没有新理由或强度变化 |
| `SUPPORTS` | 增加案例、事实或理由，不改变命题内容 |
| `AMPLIFIES` | 提高强度、扩大范围或把类别说得更绝对 |
| `QUALIFIES` | 降低强度、缩小范围、增加条件，或改为情境原因/可改变状态 |
| `REJECTS` | 否定命题本身，或否定它的成立理由 |

每条实例都直接相对上位命题选关系。不设 `INTRODUCES`，最早位置由程序推导。

来源看命题声音，不看句子的表面书写者。标题或导语中仍以“某人称／某组织认为”等方式归属给外部声音的命题，仍标 `OTHER`。进入标题或导语、被反复引述、位置醒目或全文未反驳，都不能单独推出 `ADOPTED`；只有作者以自己的声音重述为事实或结论、明确赞同，或作为前提继续推理、支持或增强时，才标 `ADOPTED`。仅作引述、转述、争议介绍或立场概括时标 `PRESENTED`。

### 3.6 命题组终态

| 字段 | 取值 |
|---|---|
| 上位命题 | 忠实、具体、可裁决的 Target-bound 判断 |
| 评价方向 | `NEGATIVE / POSITIVE` |
| 作者最终立场 | `ENDORSED / DISTANCED / REJECTED / UNCERTAIN` |
| 轨迹结果 | `MAINTAINED / STRENGTHENED / NARROWED / CANCELLED / UNCERTAIN` |
| 最终伤害门槛 | 负面命题填 `YES / NO / UNCERTAIN`；正面命题不适用 |
| 门槛依据 | 局部 YES 实例、限定/反驳依据，以及拆组的 A/B 证据 |

建设性建议不会自动抵消负面命题。只有它实际改变身份归因、范围、强度或可改变性时，才标 `QUALIFIES`。

**终态与门槛分开裁定。** `trajectory_outcome` 判断核心命题经过全文处理后是否维持、增强、收窄或取消；`final_harm_threshold` 对最终保留的命题内容重新执行 §5 的门槛四步。`NARROWED` 可以对应 `YES`，也可以对应 `NO`：范围或强度收窄后仍构成身份伤害，填 `YES`；仅剩门槛以下的内容，填 `NO`。未被取消不等于仍达门槛，出现限定也不等于降到门槛以下。必须指出原文实际改变了什么，不得只凭自省、善意、建议或环境解释判 `NO`。P2 的局部门槛保持冻结。

上述 §5 指《定义总表》的身份伤害门槛；本手册局部判断同样使用该四步。

## 4. 提交前检查

### P2

- 实例都与冻结 Target 有关；
- span 不跨块、不重叠、不跳跃拼接；
- 完整案例没有按句号切碎；
- 群体判断、个案/证据、总结、限定或反驳之间的局部作用切换已分开；
- 每条实例都填了局部门槛，只有 `YES` 填 C/X/R/A。

### P3

- 每条实例且只进入一个组；
- 实际限定负面判断的原因、建议和正面材料没有被另立成组；
- 同一 Target 下的拆组都有明确的规则 A 或 B 证据，并已先检查合并否决条件；
- 上位命题不空泛，并能覆盖组内全部实例；
- 来源、作者处理、五种关系和终态字段已填完；
- 跨组限定/反驳已在作用说明中记录。

文档标签由程序根据命题组终态推导，标注者不直接填写。
