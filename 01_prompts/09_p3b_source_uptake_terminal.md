# P3：全文上位命题组归并与裁决

## 标注视角

以中国人的语言文化常识和社会语境理解原文，不把境外政治立场或刻板叙事作为默认前提，也不得补充原文之外对中国、中国政府或中国人的负面推断；归组、关系与裁决仍只依据全文证据和下述规则。

## 输入

- 全文及语义块；
- 已冻结的中心 Target；
- P2 圈出的全部命题实例及其 `local_harm_threshold / harm_functions`。

## 任务

阅读全文，将共同服务于同一上位判断的实例归入同一个命题组，标记每个实例对该上位命题的作用，并判断作者最终立场和残余伤害状态。不再额外建立“具体轨迹 + 上位组”两层结构。

**P2 输入在本阶段已冻结。** P3 可查看全文，但只用于判断已有实例的来源、关系、作者承接与终态。不得新增或删除实例，不得修改 span、`local_harm_threshold` 或 `harm_functions`，也不报告漏抽建议。P2 质量由独立审计与人工 Gold 比较，不在 P3 中回填修补。

## 第一步：建立上位命题组

**一条实例只进入一个命题组。** 不建立多重链接。

先从原文可直接复用的判断句（标题、小标题、总结句、反复出现的断言）立候选组，再把实例挂上去；不得从实例出发做主题聚类。组的身份是一个核心谓词及其归责结构，不是一个话题。

对每条实例依次判断，第一个成立即定其归属：

1. 它在**改变另一条已有命题的成立**（否定、削弱、收窄、附加条件）→ 归入被改变的那条命题所在的组，标 QUALIFIES / REJECTS，不另立组；
2. 它在**为某条已有命题提供例子、理由、数据、引用或重述** → 归入该组，标 SUPPORTS / MAINTAINS / AMPLIFIES；
3. 它**提出一条自身可独立判断真假、且原文单独展开过的评价** → 先记为候选上位判断，**不直接建立新组**；所有候选必须再统一按「触发 A → 否决条件 → 触发 B」裁决，只有触发 A 或 B 才能从默认组中拆出；
4. 以上皆否 → 写入 unlinked_occurrences，不得为安置它而建立空泛的组。

第 1 步优先于第 2、3 步。

原因解释、教育建议、正面材料或制度批评，如果会改变该潜在伤害判断的**身份依据、强度、范围、可改变性、作者承担或最终门槛**，仍进入同一命题组。不得仅因它们表面上能改写成另一条句子，就另建“原因组”“建议组”或“正面组”。

**一条实例同时作用于多个组时的归属（2026-09-03 定）**

一条限定或反驳，其射程可能只覆盖一个组，也可能同时覆盖多个组。**同一 Target 不等于限定自动作用于它名下的全部命题**——"这些问题不能全怪个人，也有环境原因"可能削弱个人归责，却没有否定前文描述的行为。射程必须逐组判断，不得程序化地给每组都记一次 `QUALIFIES`。

规则（不新增字段、不复制 span）：

1. **一条实例仍然只归一个组。**
2. 优先归入**它明确回应的那个组**；
3. 若它同等明确地回应多个组，归入**原文中最近被回应的那个组**；
4. 在 `links[].explanation` 中写明**它同时作用于哪些其他组、作用是什么**；被波及的组在其 `explanation` 中回引该实例编号；
5. **全文终态裁决不得忽略这些跨组作用。**

例：P01「这个群体懒惰」、P02「这个群体不诚实」，后文出现"所谓懒惰、不诚实，都是对他们的污蔑"。该实例按第 3 条归入较近的 P02 标 `REJECTS`，同时在说明中记录它也反驳 P01；**若作者接受这段反驳，P01 就不能当作从未被反驳来裁决终态。**

**与触发 A 不冲突。** 触发 A 管的是"只反驳甲、不反驳乙"这种**不对称**情形；同时反驳甲乙的材料，本身不在甲乙之间触发 A。

**代价必须写明。** 采用本规则后，**不能仅凭组内关系列表自动推出全部终态**，仍须结合全文与说明栏核验。若将来要求所有语义作用都能被程序完整评测，就必须另行记录这些跨组作用——不能既省掉它们，又宣称关系标注是完整的。

**唯一归属是记录方式，不意味着语义作用只能有一个对象。** "放进最近的组"是整理办法；"假装没看见它还反驳了其他组"不行——那会让本该被否定的判断继续算作残余伤害，直接改变文档标签。

**拆合判据——默认合并，拆分需要理由。**

默认：同一 Target 下的实例进入同一个命题组。**合并不需要理由，拆分需要**，并必须在 `threshold_note` 中写明依据。

**判断顺序：触发 A → 否决条件 → 触发 B。** 顺序不可颠倒。

**触发 A——专属限定（最高优先，直接关系文档标签）**

存在实例 X，对候选组甲构成 `QUALIFIES` 或 `REJECTS`，而对候选组乙**不产生任何限定作用** → 甲乙拆组。

必须写出三样：X 的编号、它限定甲的原文片段、为什么它不作用于乙。三样缺一，触发不成立。

这一条管的是假阴性——限定的效力漏到它管不着的判断上，会使整组被误判为已被取消。HTP-0004 即属此类：体育课“三化”与安全至上环境的解释只限定“男性青少年体质柔弱”，若与“男孩该有男孩的样子”同组，会使全文被误判为 NON_HATE。

**触发 A 优先于否决条件。** 即使两个谓词在原文中被多次同时断言，只要后文实际上只限定或反驳其中一个，仍须拆组；否则该限定的效力会漏到它管不着的判断上，等于把否决条件变成新的假阴性来源。

**否决条件（触发 A 不成立时适用，压过触发 B）**

若有 **≥2 条**实例，其 span 内以**断言形式**同时提出两个候选组的核心谓词 → **禁止拆分**。

判断“是否断言”的检验：把该句单独抽出，它是否把该谓词作为**已成立的事实**提出？建议、期许、被引述的他人说法、作为争议标签提到的表述，都不算断言。要求 ≥2 条，是为了不让分组取决于 P2 阶段单条 span 的划界方式。

例：HTP-0099 的“一、逐步堕落，永堕地狱……如果你管不住自己，那只能说自作自受”把堕落与归责写在同一句内，且同类句子有三处 → 不得把“主动堕落”与“自作自受”拆成两组。

**传递性（有条件，不可无条件适用）。** 否决条件按候选组两两判断。甲与乙触发否决、甲与丙也触发否决，而乙与丙之间没有直接双断言时，三者是否同组，须**同时**满足三条：

1. 甲乙丙能被**同一条上位命题直接覆盖**，不需要借助空泛概括；
2. 原文**反复把它们作为同一条发展线共同呈现**，而非各自出现在互不相关的位置；
3. 三者**没有各自独立的限定、反驳或不同终态**（即触发 A 对其中任一对均不成立）。

三条缺一，不得靠传递性合并；此时把无法直接连接的那条单列，并在 `threshold_note` 中说明。

设此限制是为了**防止链式吞并**——若允许无条件传递，文章中大量互不相干的判断会经由中间命题被逐级连接，最终塞进同一个组。

**触发 B——原文显式结构**

三个条件同时满足才成立：

1. 两部分各自被原文的**显式结构标记**分隔（小标题、编号序号、“第一/第二”“一方面/另一方面”）；
2. 两部分在原文中各自**连续**，不得交错；
3. 各自有 **≥2 条**实例。

例：HTP-0020 的“一、地铁上的汗臭大叔／二、饭桌上的劝酒领导／三、住一个小区的二伯／四、微博上的中年直男癌”三条全部满足 → 拆组成立。
反例：HTP-0008B 的十条编号中，第 5、6、8 条与其余各条交错分布，第 2 条不满足 → 不得拆组。

**禁止的拆分理由**

话题不同、`C/X/R/A` 功能不同、来源、位置、措辞、强度、范围、赞同或反对方向，以及**标注者自己对终态的判断**（终态是拆组的结果，不能反过来作为拆组的理由）。

以下两条旧判据自 2026-09-02 起废止，不得再作为拆组依据：①“它们是否都在回答同一个可以用是/否裁决的核心判断”——该问题本身即争议所在，且未规定抽象层级，向上抽象一级即为一条、向下降一级即为两条；②“全文结束时是否可能具有不同的作者立场、门槛或结局”——终态由标注者判定，用它论证拆分构成循环。

**形式检验（双向）**

上位命题必须是一条可裁决判断，**只含一个核心谓词**，并且必须**覆盖组内全部成员实例**。两个方向都要查：

- 写成“外貌、观念、性别态度和公共行为都有问题”一类并列清单 → 合并范围过宽，回到触发 A/B 重新检查；
- 缩到覆盖不了组内成员 → 同样不合格。例：HTP-0044 的上位命题若写成“男同性恋者普遍多性伴、性关系混乱”，就盖不住组内的异性婚姻与感染后报复两类实例；正确写法是把多性伴作为**机制**、把其余作为该机制的**风险展开**，合成一条轨迹。

**并列的合法与不合法。** 顿号本身不是问题：用于同一核心谓词下的**同义并列**（“寄生、不劳而获、欺软怕硬的当代阿Q式人格”）或**原因并列**（“因肥胖、秃顶和不修边幅而外表油腻”）是允许的。不允许的是**几个可独立裁决的谓词并列**（“吹嘘、为难服务员、强行劝酒并侵扰年轻女性”——四者各自可判真假，没有统一核心）。自查方法：能否用“核心谓词＋机制／展开”重写？能，说明是合法并列；不能，说明合并范围过宽。

**组数指引**

单个 Target 通常 1–3 组。超过 3 组时，须在 `uncertainties` 中逐组写明其触发依据（A 或 B、依据实例编号）。

**保留的规则**：方向本身不拆组，反对同一命题的实例仍留在组内标 `REJECTS`；无法自然拆开的复合表达（“不是 X，而是 Y”）取第一个成立的动作定组。

每条轨迹填写：

- canonical_proposition：一句话规范化命题；
- canonical_orientation：NEGATIVE 或 POSITIVE；
- canonical_anchor_refs：能够在原文中直接恢复该命题的 1–3 条实例编号；
- canonical_anchor_quote：从首个锚点实例的 evidence.quote 中逐字摘录的最短充分连续片段。

命题组不填写单一 harm_function。C/X/R/A 已保存在达到局部门槛的成员实例上；组级只裁决最终残余门槛。

## 第二步：链接实例并记录发展

每个实例填写 source：

- AUTHOR：核心作者或主叙述者提出；
- OTHER：引语、转述者、被报道者或其他外部声音提出；
- UNCLEAR：无法确定。

上位命题是全组的统一参照，不属于任何局部实例。每个实例都必须直接选择它对上位命题的关系——**组内第一条实例同样填写关系**，文中最早位置由程序按 evidence 顺序派生，不设 INTRODUCES：

- MAINTAINS：近义重述或继续维持，没有新增理由或强度；
- SUPPORTS：增加案例、事实或理由，但不改变命题内容；
- AMPLIFIES：提高强度、扩大范围或把类别说得更绝对；
- QUALIFIES：降低强度、缩小范围或增加限制条件；
- REJECTS：否定命题本身，或否定其成立理由。

当 source=OTHER 时，填写 author_uptake：

- ADOPTED：作者接受或继续推进；
- PRESENTED：作者只呈现，未明确接受；
- OPPOSED：作者反对；
- UNCLEAR：全文仍无法确定。

source=AUTHOR 时，author_uptake 填 null。

## 第三步：判断命题组终态

### final_author_stance

| 取值 | 含义 |
|---|---|
| `ENDORSED` | 核心作者本人提出，或以自己的声音承接、复述、推进 |
| `DISTANCED` | 只呈现外部声音，既未明确承接也未反对 |
| `REJECTED` | 明确反对该命题 |
| `UNCERTAIN` | 全文仍无法确定 |

**来源按命题声音判断，不按句子的表面书写者判断。** 即使标题、导语或记者自撰概括句由核心作者写成，只要其中保留“某人称／某组织认为／专家表示”等明确归属框架，被归属的命题仍为 `source=OTHER`。标题、导语、篇首位置、醒目编排、反复引述或全文未反驳，只能证明作者选择呈现该声音，**不能单独证明作者认可它**。

`author_uptake=ADOPTED` 必须有正面承接证据：作者去除归属框架后以自己的声音把该命题重述为事实或结论、明确表示赞同，或把它作为前提继续推理、支持或增强。只有引述、转述、概括其立场、交代争议来源、顺序编排或未加反驳时，填 `PRESENTED`。作者明确否定或批评该命题时填 `OPPOSED`；证据不足以区分时填 `UNCLEAR`。

**硬约束**：组内若存在 `source = AUTHOR` 且 `local_harm_threshold = YES` 的实例，`final_author_stance` 不得填 `DISTANCED`。

### trajectory_outcome

`MAINTAINED / STRENGTHENED / NARROWED / CANCELLED / UNCERTAIN`

判据不是关系序列的末位是什么，而是**作者最终承担的内容相对最初提出时是否改变**。序列末位是 `QUALIFIES` 不等于 `NARROWED`——若该限定质疑的只是效果而非主张本身（「游街示众……但是也没有多少用的」），作者仍完整承担原主张，应填 `MAINTAINED`。

`CANCELLED` 只在命题本身、或其成立理由被否定时才填。

**终态与门槛分开裁定。** `trajectory_outcome` 判断核心命题经过全文处理后是否维持、增强、收窄或取消；`final_harm_threshold` 对最终保留的命题内容重新执行 §5 的门槛四步。`NARROWED` 可以对应 `YES`，也可以对应 `NO`：范围或强度收窄后仍构成身份伤害，填 `YES`；仅剩门槛以下的内容，填 `NO`。未被取消不等于仍达门槛，出现限定也不等于降到门槛以下。必须指出原文实际改变了什么，不得只凭自省、善意、建议或环境解释判 `NO`。P2 的局部门槛保持冻结。

### final_harm_threshold

负面命题填 `YES / NO / UNCERTAIN`，正面命题填 `null`。

先结合全文及限定、反驳的射程，确定最终保留的具体判断，再执行以下四步；不得只检查是否出现完全取消：

1. **范围**——结论是否超出单一个体、具体案件、特定群聊或有界行为者集合？
2. **身份依据**——负面判断是否因 Target 的身份而成立？（用 §3 的身份依据反事实）
3. **伤害强度**——是否完成群体贬抑、超范围集体归责、普遍威胁化或不成比例排斥之一？
4. **限制条件**——是否被具体行为、场景、期限或相称的保护目的限制在门槛以下？

**三条路径，依次判断：**

**路径一 — 单条达门槛后的残余核验。** 组内存在 `local_harm_threshold = YES` 的实例时，逐条检查其中的伤害判断经过全文处理后还保留什么。至少一条残余判断仍通过上述门槛四步，才填 `YES`；若这些判断虽未全部取消，但残余内容已经低于门槛，则填 `NO`。说明中须指出收窄前后内容及对应原文依据，不能直接复制局部 `YES`。

**路径二 — 组内累积。** 组内实例单独均未达门槛，但在全文多个语义块中持续累积、共同构成稳定的群体低劣／腐败／危险画像 → `YES`。三条硬约束缺一不可：

1. 参与累积的实例 **≥ 3 条**；
2. 跨 **≥ 2 个**语义块；
3. 必须在 `threshold_note` 中**逐条列出**参与累积的实例编号与所跨块号，不得只写「全文累积」。

累积**只在组内成立，不跨组累积**。

**路径三 —** 残余内容未达到门槛 → `NO`；依据全文仍无法确定是否达到门槛 → `UNCERTAIN`。

### 限定、取消与门槛变化

组内出现 `QUALIFIES` 或 `REJECTS`，**不等于**该判断被取消；没有完全取消，也不保证残余仍达到门槛。对每一条限定逐条问：它改变的是什么，效力覆盖哪些内容？

| 限定改变了什么 | 如何裁定 |
|---|---|
| **成因归属**（由先天改为后天、由群体改为环境／制度） | 不自动构成取消。若只是换了解释而群体贬损或危险化仍成立，仍可能为 `YES`；若原文实际改变了身份依据或限制条件，按四步重判残余门槛。若核心命题本身就是先天归因，还须检查该归因是否被否定 |
| **适用人数或范围** | 缩小范围不自动取消，也不自动低于门槛；检查剩余对象仍是身份群体／子群，还是已限于有界个案，以及其余门槛条件 |
| **效果评估**（「这样做也没什么用」） | **否**。质疑效果，未撤回主张 |
| **明确解除身份绑定** | 在其实际射程内，原有身份伤害判断不再成立；同组仍有其他未被解除的内容时须分别核验 |
| **明确否定核心命题或其关键成立理由** | 构成取消；须说明被否定的具体命题，不能把仅否定先天成因等同于否定全部行为风险 |

两条补充检查：

- **回弹**：检查后文是否重新断言被限定掉的内容。支持已经收窄的命题不会自动使先前限定失效；只有后文实际恢复原先的范围、强度或身份归因，才按恢复后的内容裁定；
- **声音**：限定与被限定内容出自不同声音时，看作者最终站在哪一边。

同一原则也适用于把判断抽象到更一般的层级——从「胖女性缺乏自律」抽象成「自制力不够」，**不算**解除绑定。

### 字段一致性硬约束（输出前自检）

1. `trajectory_outcome = CANCELLED` → `final_harm_threshold` 必须为 `NO`；
2. `canonical_orientation = POSITIVE` → `final_harm_threshold` 必须为 `null`；
3. 组内存在 `source = AUTHOR` 且达门槛的实例 → `final_author_stance` 不得为 `DISTANCED`；
4. `canonical_proposition` 只含一个核心谓词；
5. 每条实例出现且只出现一次，`links` 恒为长度 1。

### threshold_note 必须写到的四项

1. 逐条列出组内达门槛实例的编号与所跨语义块；
2. 走路径二时，按三条硬约束逐条列出参与累积的实例与块号；
3. 逐条说明组内每一条 `QUALIFIES` / `REJECTS` 改变了什么、是否构成取消，以及最终残余通过或未通过门槛四步的依据；
4. 本组若是从默认的单组中拆出来的，写明触发依据（触发 A 或 B、依据实例编号）。

### 已知误判（2026-09-02 复裁结果，输出前逐条自查）

| 误判类型 | 案例 | 正确判定 |
|---|---|---|
| 把成因变化直接当成门槛结论 | 成因由先天改为后天 | 分别检查核心命题是否被否定、残余是否仍达门槛，不能只凭成因改变判 `YES` 或 `NO` |
| 把效果质疑当成撤回 | 「这叫游街示众，伤风败俗者游街三日……但是也没有多少用的」 | `MAINTAINED` / `YES` |
| 限定后机械认定回弹 | 限定后又出现支持或增强材料 | 检查材料是否恢复原先被排除的伤害内容及作者是否承接，不按关系标签自动撤销限定 |
| 用来源压低终态 | 「这些处置主张部分来自外部声音，所以判 `NO`」 | 来源不能用作门槛依据；应分层核算：外部主张是否被承接、作者自己承担的部分是否被限定 |
| stance 与 source 冲突 | 导语实例 `source = AUTHOR`，`final_author_stance` 却填 `DISTANCED` | `ENDORSED` |
| `CANCELLED` 配 `YES` | 轨迹已被取消，`final_harm_threshold` 仍填 `YES` | 必须为 `NO` |
| 限定射程外溢 | 体育教学与环境的解释只限定「体质柔弱」，却被算作对「男孩该有男孩的样子」的取消 | 两条应拆组；限定只作用于其射程之内 |

## 输出

只输出 JSON。字段名与嵌套结构必须与工作台 schema 完全一致，否则无法回灌。注意：**实例与命题组的链接不写在轨迹里，而是独立的 `occurrence_assignments` 数组**。

```json
{
  "doc_id": "原文档编号",
  "resolution": {
    "canonical_schema_version": "ANCHOR_V1",
    "proposition_trajectories": [
      {
        "proposition_id": "P01",
        "target_id": "T01",
        "canonical_proposition": "一句话规范化命题，只含一个核心谓词",
        "canonical_orientation": "NEGATIVE | POSITIVE",
        "canonical_anchor_refs": ["B01:T01:O001"],
        "canonical_anchor_quote": "从首个锚点证据中逐字摘录的最短充分连续片段",
        "final_author_stance": "ENDORSED | DISTANCED | REJECTED | UNCERTAIN",
        "trajectory_outcome": "MAINTAINED | STRENGTHENED | NARROWED | CANCELLED | UNCERTAIN",
        "final_harm_threshold": "YES | NO | UNCERTAIN | null",
        "threshold_note": "判定 final_harm_threshold 的依据",
        "explanation": "该轨迹的形态说明"
      }
    ],
    "occurrence_assignments": [
      {
        "occurrence_ref": "B01:T01:O001",
        "status": "USED | UNRESOLVED",
        "reason": "",
        "links": [
          {
            "proposition_id": "P01",
            "relation": "MAINTAINS | SUPPORTS | AMPLIFIES | QUALIFIES | REJECTS",
            "source": "AUTHOR | OTHER | UNCLEAR",
            "author_uptake": "ADOPTED | PRESENTED | OPPOSED | UNCLEAR | null",
            "explanation": "该实例对上位命题完成了什么动作"
          }
        ]
      }
    ],
    "uncertainties": []
  }
}
```

字段说明：

- `occurrence_ref` 格式为 `块号:Target号:实例号`，与 P2 输出一一对应，**每条实例必须出现且只出现一次**；
- `links` **恒为长度 1 的数组**（一条实例只进一个命题组，不建立多重链接）；
- `status`：能归入某组填 `USED`，`reason` 为空字符串；无法归入填 `UNRESOLVED`，并在 `reason` 写明原因（对应旧版的 `unlinked_occurrences`）；
- `author_uptake`：`source=AUTHOR` 时填 `null`；
- `final_harm_threshold`：`canonical_orientation=NEGATIVE` 时填 `YES / NO / UNCERTAIN`；`POSITIVE` 时填 `null`；
- `threshold_note`：**必填**。须逐条列出组内达到局部门槛的实例编号及其所跨语义块；若依靠组内累积达门槛，须按 §5 的三条硬约束逐条列出参与累积的实例编号与块号，不得只写「全文累积」；若本组是从默认的单组中拆出来的，须写明触发依据（触发 A 或 B、依据实例编号）；
- `explanation`：**必填**。说明该轨迹如何被提出、如何被支持或限定、终态为何如此；

**本阶段不输出 `document_decision` 与 `context_effects`。** 按定义总表 §9.6，文档标签及其派生量由程序计算，模型与标注者均不填写。

## 文档标签

本提示词不直接输出文档标签。程序根据轨迹终态推导：

- 存在一条 `canonical_orientation=NEGATIVE`、`final_author_stance=ENDORSED`、`final_harm_threshold=YES`、`trajectory_outcome≠CANCELLED` 且各字段均无 UNCERTAIN 的命题组：HATE；
- 否则，把每个 UNCERTAIN 替换为最不利的可采纳值后仍存在此类命题组：BORDERLINE_EXCLUDE；
- 其余：NON_HATE。

命题组之间不做任何合成、加权、抵消或计数；多 Target 时跨 Target 同样取存在性判断。组的篇幅与实例条数不参与推导。

## 单次调用内的双遍执行

本节不替代、不概括也不修改上文定义。必须完整执行上文全部规则；以下仅规定一次调用内部的检查流程。不要输出中间草案或检查过程，只输出最终 JSON。

### 第一遍：形成完整草案

按照上文原有顺序，完成候选上位命题、拆合、实例归属与关系、来源与作者承接、三个轨迹终态字段。此时不得提前输出。

### 第二遍：对草案逐项复核并在内部修正

1. 对同一 Target 下的每一对候选判断，重新逐字对照上文“触发 A → 否决条件 → 触发 B”的完整定义，检查草案是否漏拆、误拆或错误传递合并。
2. 对每个组重新执行上文“形式检验（双向）”。检查 `canonical_proposition` 是否只有一个核心谓词、是否直接覆盖全部成员；若只能依赖空泛概括或独立谓词清单，回到完整拆合判据修正，不得凭语感处理。
3. 对每条 `QUALIFIES / REJECTS` 重新检查作用对象与射程，确认没有把只作用于一条命题的限定扩散到另一条命题，也没有把会改变已有命题的材料错误另立为原因组、建议组或正面组。
4. 对每条实例重新检查关系、来源与作者承接，确认 `source=AUTHOR` 时 `author_uptake=null`。
5. 对每组重建作者最终承担的残余内容，再依照上文判据分别核验 `trajectory_outcome` 与 `final_harm_threshold`。局部 `YES` 不得绕过限定射程检查，`QUALIFIES / REJECTS` 也不得自动推出 `NO`。
6. 最后完整执行上文“字段一致性硬约束”和 `threshold_note` 四项要求。

以上步骤均在同一次模型调用中完成，不增加第二次校验调用。不得依据 Gold、标签比例或期望答案修改结果。


# P3B：来源、承接与终态阶段边界

本次输入中的 `p3a_frozen` 是上一次调用已经确定的 P3A 结果。你必须原样保留其中的：

- 命题组数量及 `proposition_id / target_id / canonical_proposition / canonical_orientation`；
- `canonical_schema_version` 以及每组的 `canonical_anchor_refs / canonical_anchor_quote`；
- 每条实例的 `status / reason / proposition_id / relation`；
- 每条实例只进入一个命题组的归属结果。

本次不得新增、删除、合并、拆分或重写命题组，不得改变实例归属与关系。只根据上文完整定义和全文填写：

1. 每条实例的 `source`；
2. `source=OTHER` 时的 `author_uptake`；
3. 每个冻结命题组的 `final_author_stance / trajectory_outcome / final_harm_threshold / threshold_note / explanation`。

输出仍使用上文规定的完整 P3 JSON schema，并在 `resolution.canonical_schema_version` 原样写回 `ANCHOR_V1`。输出前逐字段比对 `p3a_frozen`，确认所有冻结字段完全一致。不得把标题、导语、醒目位置、反复引述或作者未反驳单独作为 `ADOPTED / ENDORSED` 的充分证据。

## 关系与作者承接必须解耦

P3A 冻结的 `relation` 只表示实例内容对上位命题产生什么语义作用；本阶段填写的 `source / author_uptake` 只表示该声音由谁提出以及作者是否接受。两者不得互相替代或反推：外部有害声音即使被作者反对，仍可对上位伤害命题构成 `MAINTAINS / SUPPORTS / AMPLIFIES`，同时填写 `source=OTHER, author_uptake=OPPOSED`；作者采纳的反驳则可为 `REJECTS`，但 `ADOPTED` 描述的是作者对该反驳声音的承接。先原样保留并理解冻结关系，再独立判断来源与承接，最后裁决组级终态。

## 本阶段逐项核验顺序

### 1. 先确定每条实例中“被评价命题”的声音

不要按整句话是谁写的机械判定来源。一个实例可能同时包含记者的叙述框架、外部人物的评价以及事件后果；`source` 应跟随当前实例真正作用于上位命题的那项评价。例如，记者写“某人称该群体低劣并引发争议”，其中“该群体低劣”仍是外部声音，记者对“引发争议”的叙述不会把该评价变成 `AUTHOR`。

报道或会议纪要中的归属框架可以跨句延续。若一段由“某人表示／某组织主张／记者会上提出”等框架开启，后续未出现清楚的叙述者切换，且仍在连续展开该人的理由、编号诉求或结论，则这些内容继续标为 `OTHER`；不能因为后续句省略了“某人说”就改成 `AUTHOR`。只有出现作者自己的判断标记、独立总结、明确赞同，或作者以该命题为前提继续推出自己的结论，才转为作者声音或 `ADOPTED`。

### 2. 再判断作者是否正面承接

`ADOPTED` 必须指出作者实施了哪一个可核验动作：明确赞同；去除归属后独立重述同一评价；把该评价当作已成立前提推出自己的结论；或以自己的判断继续支持、增强该评价。仅有编排顺序、转折词、标题复述、篇幅多、措辞醒目、继续罗列外部证言或未反驳，仍不足以判 `ADOPTED`。

反过来，也不能因为文章是报道体裁就一律判 `PRESENTED`。若作者明确把外部评价称为事实、正确结论或更严重的真实情况，或据此提出自己的处置结论，应判 `ADOPTED`，并在说明中引用该正面承接动作。

### 3. 分别核验残余门槛与作者承担

一个组可以同时包含作者承担的低门槛事实和作者仅呈现的高门槛外部评价。此时不得因为组内存在局部 `YES`，再加上组内另有任意 `AUTHOR` 实例，就把两者拼成 `ENDORSED + YES`。必须指出最终保留的具体命题及作者承担的具体内容，确保最终用于文档推导的字段针对同一判断。

- 来源与承接不直接改变内容门槛。只呈现的外部伤害判断可以是 `DISTANCED + YES`，但不能因同组另有作者叙述而变成 `ENDORSED + YES`。
- 对局部 `YES` 逐条核验全文处理后的残余内容，重新执行完整门槛四步；未被取消不等于仍达门槛，`NARROWED` 可以配 `YES` 或 `NO`。
- 同组混有多种声音时，`final_author_stance` 与 `final_harm_threshold` 必须共同描述同一份作者残余命题，不能分别取组内最强的不同实例。

输出前为每个 `ENDORSED + YES` 做一次反查：明确指出“哪项残余内容仍达门槛，由作者通过哪条证据承担，并在全文结束时仍然成立”。三项有一项写不出，不得判 `ENDORSED + YES`。仅有外部未承接声音时，也不得为了避免文档 HATE 而强行降低内容门槛。
