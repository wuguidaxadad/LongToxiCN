# P2A：抽取完整的局部评价实例（DeepSeek v9）

## 标注视角

以中国人的语言文化常识和社会语境理解原文，不把境外政治立场或刻板叙事作为默认前提，也不得补充原文之外对中国、中国政府或中国人的负面推断；实例抽取仍只依据原文与下述规则。

## 任务

输入一个冻结 Target 和一个完整语义块。只抽取本块中与该 Target 直接相关的命题实例；不跨块，不修改 Target，不判断伤害门槛、C/X/R/A、来源、作者立场、命题组或全文标签。

实例是围绕 Target 连续完成一次局部话语动作的**最大连续文本**，不是逻辑原子，也不是最短有害短语。

## 一、确定最终边界

先找以下完整单元：群体评价、完整案例、成组证据、群体总结、限定、反驳、应对。`local_role` 只标整条实例的主导作用；一条实例内部可以含有短理由、简短事实、引语或直接结论，不能因为内部成分名称不同就继续切碎。

### 合并为一条

1. 同一群体判断及其紧随的短理由、简短事实依据、换词说明和直接结论；
2. 同一人物或事件的背景、行为、经过、台词、结果和直接收束评论；
3. 同一调查、同一列表模块或同一组成组证据；
4. 只为紧随内容服务的非纯编号标题、设问、人物小标题和来源框架。

### 拆为不同条

1. 群体判断转入具有自身对象、起止和展开过程的完整案例/调查/数据/历史材料；
2. 完整案例或独立证据结束，回到适用于 Target 的群体总结、诊断或一般结论；
3. 开始另一人物、另一事件或另一场景，并形成新的完整案例；
4. 开始另一项可区分的群体判断，而不是前项的理由或结论；
5. 开始限定、反驳、纠正、警告、建议、保护、要求或处置；
6. 说话者改变，并且新声音提出了可区分的新判断。

句号、引号、转折词、故事推进、单纯说话者变化和是否有害都不能单独决定边界。同一句内部无法自然分开时保持一条。

## 二、用以下对照校准粒度

### 对照 1：短依据不拆

“某群体文化水平低。某项考试成绩比其他群体低。可见其整体素质不高。”

若中间只是紧随判断的一条简短依据，三句构成“判断—短依据—直接结论”的紧凑评价，合为一条；不要拆成评价、证据、评价三条。

### 对照 2：完整案例与总结拆

“某群体不可靠。某甲在一次事件中……随后……最终……。这说明该群体普遍不可靠。”

分为群体判断、某甲的完整案例、回到群体层的总结三条。案例内部不随情节拆。

### 对照 3：两个案例拆

“某甲在事件一中……结果……。某乙在事件二中……结果……。”

即使两个案例支持同一判断，也分成两条完整案例；不能因 `local_role` 都是 `EVIDENCE` 而合并。

### 对照 4：限定/反驳拆

“人们认为该群体都有缺陷。但专家指出这只是少数个案，并非群体特征。”

前项评价与后项限定/反驳分开。

### 对照 5：紧凑攻击不拆碎

“该群体更加恶劣。若干事件就是证据。由此可见他们整体危险且缺德。”

若事件只以一句或简短并列列出，没有形成独立案例过程，整段是一次连续升级的群体评价，合为一条。

## 三、入选与排除

保留：Target 的正负评价；直接支持其判断的完整案例或证据；增强、限定、反驳和应对；被 `scope` 纳入的代表人物、交叉子群及代词；直接用作评价当前 Target 的比较材料。

排除：只有身份提及，普通时间地点背景，网页残留，纯数字/列表编号，独立评价另一群体，不支持或改变 Target 判断的一般事实与建议。关于另一群体的材料若直接说明为什么要对当前 Target 提出评价或应对，仍保留。

必要主语、否定、范围词和引语标记必须保留。引语前后相邻的来源称谓与转述框架随引语保留；引出下一条发言的框架不并入上一条。孤立闭合标点随前文。

## 四、简述

`normalized_proposition` 用一句话忠实说明整条实例对 Target 做了什么，保留范围、条件、否定、个案/群体层级和正反方向。案例需说明它呈现或支持什么 Target 判断。不得新增原文没有的动机、因果或道德标签。

## 五、输出前复核

1. 逐句检查是否漏掉 Target 相关材料；代表人物或代词未重复群体名不等于无关。
2. 有无把完整案例、成组证据或紧凑评价拆碎。
3. 有无把两个完整案例、不同群体判断、群体总结、限定、反驳或应对合在一起。
4. 每条连续、互不重叠；不按期待数量或标签比例调整。

## 输出

只输出严格 JSON：

```json
{
  "doc_id": "输入文档号",
  "block_id": "输入块号",
  "focal_target_id": "输入Target号",
  "reviewed": true,
  "coverage_map": [
    {
      "start_id": "S001",
      "end_id": "S003",
      "local_role": "EVALUATION|EVIDENCE|QUALIFIER|REBUTTAL|RESPONSE|EXCLUDE"
    }
  ],
  "proposition_occurrences": [
    {
      "occurrence_id": "O001",
      "local_role": "EVALUATION|EVIDENCE|QUALIFIER|REBUTTAL|RESPONSE",
      "normalized_proposition": "忠实的一句话简述",
      "evidence": [{"start_id": "S001", "end_id": "S003", "quote": "连续原文"}]
    }
  ]
}
```

`coverage_map` 覆盖每个句元一次且不重叠，它表示**最终分组**，不是更细的预切分。除 `EXCLUDE` 外每段都对应一条实例。没有相关实例时返回空数组并把全块标为 `EXCLUDE`。不输出 JSON 之外的内容。
