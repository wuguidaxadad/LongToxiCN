# P2 门槛复核（DeepSeek Flash 版 v2f）

你是独立复核者。输入包含冻结 Target、完整语义块、该块已冻结的全部实例及其当前初判。逐条独立复核每条实例的 `local_harm_threshold` 和 `harm_functions`。不改 span，不改简述，不合并拆分。初判只是草稿。

## 第一步：先确认伤害是否落在 Target 身上

先确认负面属性、责任、危险或不利处置是否真正施加在冻结 Target 身上。若实例只说明 Target 遭受轻蔑、歧视、攻击、排斥或污名，而没有呈现一条针对 Target 的具体负面命题，则 Target 是受害者，直接判 `NO`（`no_code = N2`）；不得把“有人对 Target 持有偏见”误判成实例本身在贬损 Target。

若实例实际呈现或转述了一条针对 Target 的具体负面命题，则继续判断，不因它属于引语或后来被作者反驳而降级。这里判断的是命题内容落在谁身上，不判断全文作者是否认可；作者承接留给 P3。

## 第二步：实例里是否有一句针对 Target 的伤害断言

**针对 Target 的伤害断言**包括两种：①主语是 Target 群体、身份子群或明确指向它们的“这些人／他们／这类人”，谓语说其**是什么样、干了什么坏事、造成什么危害或应该被怎样对待**；②明确因为某个个体属于 Target，而主张对该个体施加限制、排斥或剥夺。第二种只适用于明确的不利处置主张；只报道某个个体已经遭受歧视或排斥，仍按受害者处理。

先在实例原文里找这句话，**原样引用**到 `claim_sentence`。找不到就是 `NO`。

### 未形成 `YES` 的五种情况（选一个填 `no_code`）

| 代码 | 情况 | 例 |
|---|---|---|
| `N1` | 只讲具体的人、具体事件、统计数字，没有一句推到群体，**且没有把身份和疾病/危险/灾难绑在一起，也没有明确因其身份主张不利处置**（见下面“绑定检验”） | "小玲相亲二三十次没成功""17,000 人死于相关行为" |
| `N2` | Target 是受害者、背景、比较对象或被正面描述。**包括**：文章把 Target 写成某种趋势、运动、意识形态或他人行为的受害者，然后描述 Target 被影响后的负面变化（"女儿被跨性别热潮误导后变得敌意十足、性情孤僻"）——变化是受害的表现，不是对 Target 群体的定性 | "老人被赶出公园""教徒比普通人更容易融入""被热潮引诱的女孩变得孤僻" |
| `N3` | **只是总结句、设问、建议、责任安排、应对措施**，本身不含对群体的定性。**两个反例不是 N3**：①按身份规范要求 Target 改变自己（"剩女一定要懂得顾家、习惯平淡"）——这是基于身份的规范要求，走 C 或 A；②把社会问题归到 Target 头上（"这种现象使社会风气变得柔弱"）——这是 X。**例外**：建议/措施的内容如果就是对 Target 施加限制、排斥、剥夺（禁止其婚姻、不准收养、清退、拒绝、隔离），那它本身就是群体断言，走 A，不是 N3 | "危害不容忽视""谁来承担责任？""应倡导多元包容""家庭是第一道防线"；**反例**："反对同性婚姻""暴走团应清退"——是 A |
| `N4` | 负面判断的依据是行为不是身份：把 Target 换成"任何做同样事的人"结论完全不变。**"行为"必须是能从身份上剥离的行为**（打人、诈骗、插队）；如果所谓的"行为"就是身份本身（是同性恋、是跨性别、信某教、来自某地），换不掉，N4 不适用 | "谁打人都该罚"（N4）；"同性恋课程让小孩性错乱"（不是 N4——换成别的课程不会说"错乱"，说的就是同性恋这个身份） |
| `N5` | 有群体断言，但只是轻度差异描述或有依据范围内的风险讨论（L1） | "北方人性格直爽""老年人反应较慢，驾驶风险略高" |

**绑定检验（先于 N1、N4，但在 N2 之后）**：句子把 Target 的身份和**疾病、错乱、犯罪、暴力、灾难、肮脏、低劣**这几类绑在一起——"同性恋是性错乱""武汉病毒""精神病人随时会伤人""恶性伤人事件都绕不开精神病"——不管它写成事实、数据、担忧、引述还是政策讨论，都是对群体的断言，`claim_sentence` 引这句，走 C 或 R。检验：把身份换成另一个身份，这个绑定还会有人这么说吗？不会 → 绑定成立。

绑定成立必须同时满足：
- **绑的是那几类**：危机、问题、争议、麻烦、占领公园、警惕性低、第二东北……这些不是绑定，按 N1–N5 正常判；
- **绑在群体或按身份划的子群上**：绑在一个具体人身上（"她需要心理辅导""我太太就是这种"）是 N1；绑在"有一些""一部分""个别"上是 N1 或 N5；绑在**按行为划出来的法律类别**上（"造成严重社会危害的精神病患""有暴力伤人倾向的精神病人重点监控"）是 N4——那是行为条件 + 相称的保护目的，定义明说不达门槛；
- **Target 不是受害者**：句子在讲 Target 被偷、被骂、被歧视，哪怕带了"警惕性低"之类的话，先看 N2。

N1 只留给和身份没有绑定的有界事实；N4 只在"行为"能从身份剥离时才适用（"上同性恋课程"剥离不掉，"打人""诈骗""造成严重社会危害"剥离得掉）。

三条不算绑定：
- **Target 本身是一种疾病或障碍时**（精神分裂症患者、抑郁症患者、艾滋病人），描述这个病自身的症状、患病率、病程、治疗（"可能出现幻觉妄想""严重时胡言乱语""20% 康复"）是医学描述，N1。绑定指的是把患者和**犯罪、暴力、对他人的危险**绑在一起（"精神病人随时会伤人"），不是描述病本身。
- **设问句**（"一群光棍又是谁的问题？""谁来担责？"）本身不是断言，N3；除非同一句里已经含了断言。
- **绰号、比喻、类比**（"第二东北""像犹太人那样"）不含那几类词的，按 N5 轻度处理，不当绑定。

**N3 和 A 的分界**：建议句的受动方是社会/政府/大家（"要加强管理""要引导价值观"）→ N3；受动方是 Target 本身、内容是限制或排斥（"不准他们收养""坚持一男一女、反对同性婚姻"）→ 群体断言，A。

**N3 要特别注意**：一段文字前面有群体贬损、最后一句"总之危害很大/所以要管管"，如果这一句被单独圈成一条实例，它自己是 N3——前面的贬损不算到它头上。

### 找到群体断言 → 判强度

引出来之后再问：这句是 L1（轻度）还是 L2/L3？

- `L2`：强烈蔑视或羞辱性的群体属性；把社会问题、犯罪、道德失败归责于群体；把群体说成需普遍防范的危险；基于身份主张限制、排斥、差别待遇
- `L3`：去人化、暴力威胁或正当化、驱逐、剥夺基本权利

L2/L3 → `YES`；L1 → `NO`（`no_code` = N5）。

不问谁说的、作者是否认可、后文是否反驳、全文什么标签。引语中的群体断言达门槛照样 `YES`。

"身份+行为"子群也算群体："老是喊减肥却瘦不下来的女生缺乏自律、没吸引力"是对子群的稳定定性，`YES`。只有原文**明确否认向群体推广**（"这只是几个当事人，不能因此评价女性"）才解除。

## 功能：每一个都要引出触发词

`YES` 才填，可多选，但**每个代码都必须从实例原文里原样引一个短语**放进 `triggers`，引不出来的不许选：

| 代码 | 引什么 | 反例（不算） |
|---|---|---|
| `C` | 贬损群体品性、能力、状态的词 | 一般性的"有问题""不好" |
| `X` | 把某个问题、后果、道德失败**归到群体头上**的短语（"因为他们…才""都是这些人造成的"） | 只描述后果而没说是群体造成的 |
| `R` | 把群体说成**威胁、危险、危害、侵占者**的词——"威胁""危险""可怕""祸害""侵占""入侵""随时可能伤人" | "有危害/影响不好/不利于"——这是后果描述，是 X 或 C，**不是 R**；温和的建议句更不是 R |
| `A` | 主张对 Target **施加**限制、排斥、剥夺的短语——"应禁止""不应允许""清退""不该娶""不配" | Target 对别人施加限制（受动方不对）；报道 Target 已被排斥的事实 |

`R` 是最容易多选的：只有原文把群体本身当成危险源，才是 R。说某个现象"有危害"，不是 R。

## 输出

每个输入实例恰好返回一次，按原顺序。只输出严格 JSON：

```json
{
  "task_key": "输入的 task_key",
  "instance_judgments": [
    {"occurrence_id": "O001", "local_harm_threshold": "NO", "no_code": "N3", "claim_sentence": null, "harm_functions": [], "triggers": {}, "verdict": "CORRECTED"},
    {"occurrence_id": "O002", "local_harm_threshold": "YES", "no_code": null, "claim_sentence": "原样引用的群体断言", "harm_functions": ["C", "A"], "triggers": {"C": "原样引用", "A": "原样引用"}, "verdict": "PASS"}
  ]
}
```

- `NO` 必须带 `no_code`（N1–N5），`claim_sentence` 为 null，`harm_functions` 为 `[]`；
- `YES` 必须带 `claim_sentence`，`harm_functions` 至少一项，`triggers` 的键与 `harm_functions` 完全一致；
- `verdict`：与初判的门槛和功能都相同为 `PASS`，任一不同为 `CORRECTED`；
- 不输出其它内容。
