你会收到一篇带 S 编号的中文长文，以及本任务统一使用的操作性定义。请只依据原文和该定义，自行识别中心身份 Target，并完成命题实例定位、逐实例局部门槛判断、命题组追踪、声音归属、终态裁定和文档标签判断。S 编号只用于报告原文范围，不表示语义块边界。

# 统一操作性定义（v6草稿，确定终态与二分类）

## 任务与判断对象

依据完整原文，自行识别中心 Target 和命题实例，将实例组织为命题组，判断实例关系、声音来源和每组终态，并提交文档标签。句元编号只用于定位，语义分块不作为输入或输出要求。以中文语言文化常识理解原文，只使用文本证据，不补充群体属性或作者动机。

本任务判断全文结束时，核心作者是否仍提出、采纳或延续了至少一项针对 Target 的伤害性评价。文中曾出现有害表达，不直接决定文档标签。不同评价分别判断，反驳只能改变它实际回应的评价。

## 身份伤害门槛

身份伤害指基于 Target 身份，对群体或身份化子群作出达到一定程度的负面定性，包括能力、品性、可信度、社会价值或婚恋价值的负面定性，以及集体归责、将群体构造成普遍危险源，或主张不成比例的限制、排斥与剥夺。不要求达到明显羞辱的程度，也不要求辱骂、强烈敌意或行动号召。

判断需同时考虑负面内容、身份依据、范围与程度。将群体定性为低劣、不可信、价值较低、应承担集体责任或需要普遍防范，属于伤害判断；中性差异或不足以形成上述定性的轻微差异，本身不达到门槛。具体个人或事件的负面事实，只有在原文将其用于群体定性时才形成身份伤害；明确因为个体属于 Target 而主张对其施加不利处置，也须判断。

伤害门槛针对的是将负面属性、集体责任或危险归于 Target，或者认可对 Target 施加不利处置的评价。作者认可“Target 受到歧视、忽视或伤害”这一事实，不等于认可造成该处境的负面评价或不利处置。

区分“Target 被负面评价”与“文本仅描述 Target 受到伤害”。单纯报道受害处境不构成对 Target 的伤害评价；若实际呈现了针对 Target 的负面命题，仍应识别该命题，另行判断作者是否承担它。事实、统计或解释性表达也须按其实际断言判断，不能仅凭表达形式认定有害或无害。对可与身份分离的具体行为的批评，不等于对身份群体的定性。

局部内容达到门槛，与作者最终承担该伤害是两个判断。引述中的伤害可以被作者反对；作者认可的负面判断也可能在后文被限定。最终门槛只针对全文结束后仍由作者承担的具体内容。

## 命题实例与边界

实例是连续原文中一次完整的局部评价作用，包括正负评价、案例、数据、理由、增强、限定、反驳及相关应对。不能只找负面措辞；改变评价归属或结局的非负面材料同样需要提交，代词或代表人物未重复 Target 名称也不表示无关。只有身份提及、无关背景或不支持也不改变 Target 评价的一般建议不算实例。

同一完整案例的必要背景、经过、台词、结果与直接收束保持一条；紧凑判断及其短理由、直接结论也保持一条。进入另一个独立案例、独立证据展开、群体总结或新的限定反驳作用时分别提交。句号、引号、单纯说话者变化不单独决定边界。保留必要主语、范围、否定与引述框架；不截掉决定反语或否定含义的上下文。

每条范围连续、互不重叠。用于终态判断的关键支持、限定、反驳和作者承接材料应作为实例提交；终态依据引用已提交实例。确实相关但无法归组的实例放入 unresolved_instances。

## 核心命题与归组

命题组以同一核心评价为组织单位，将提出该评价、为其提供案例或理由，以及对其增强、限定或反驳的实例归在一起。判断是否属于同组，依据是这些实例是否围绕同一项评价展开，而不是它们是否来自同一段落、同一声音或同一案例。原因解释和改善建议若回应的是该评价，也应归入同组。每组的核心命题须能具体概括组内评价，不能仅因涉及同一 Target 或话题就合并。若一项限定或反驳只改变评价甲、而不影响评价乙，则应将两者分开。

同一 Target 的相关评价原则上合并组织，拆组须有明确依据。案例、原因解释、改善建议，以及针对原评价的正面回应，不因能够单独表述就另立命题组。专属限定或反驳要求拆组；原文明示分开并各自充分展开的独立评价，也可分别成组。合并仍须围绕具体核心评价，不得用宽泛话题强行容纳无关判断。

规范命题写明 Target、一个核心评价谓词及必要范围条件，并以原文实例为锚点。不能拼成多个不相关评价的清单，也不能概括得过窄而遗漏组内评价。对潜在伤害命题保持其伤害方向，作者反对体现在实例关系和终态中。合成示例：原文先引述“某群体普遍危险”，随后否定这一说法，核心命题仍写“该群体普遍危险”，后项为 REJECTS；不要改写成“该群体遭受污名”。

实例只归一个组。若同一限定或反驳明确作用于多个命题，记录在其直接回应的组中；同等明确时记录在最近被回应的组中。裁定其他组时仍须考虑它的实际作用，不能把记录归属误当成作用范围。终态依据可引用其他组已提交的实例。

## 关系、来源与作者承接

每条实例相对于本组核心命题标注关系，包括组内第一条：MAINTAINS 为近义重述或继续维持；SUPPORTS 为新增案例、数据、事实或理由；AMPLIFIES 为提高强度、扩大范围或使判断更绝对；QUALIFIES 为缩小范围、减轻程度或增加条件；REJECTS 为否定核心命题或其关键成立理由。先区分限定和反驳，再区分重述、证据支持与强度升级。案例不是仅因内容负面就标为 AMPLIFIES。

source=AUTHOR 表示核心作者或主叙述者自己的判断；OTHER 表示引述、受访者、网友评论或其他外部声音；UNCLEAR 表示无法确定。主文或正式回答与后附评论不能合成一个作者。来源按命题实际归属判断，即使句子由作者书写，保留明确引述框架的命题仍属于外部声音。

OTHER 的 author_uptake：ADOPTED 为作者明确赞同、用自己的声音重述为事实或作为前提继续推论；PRESENTED 为只呈现、未明确接受或反对；OPPOSED 为明确反对；UNCLEAR 为无法确定。其他 source 的 author_uptake 填 null。引述位置、重复次数或未加反驳不单独证明采纳。实例关系与作者承接分开判断：一条引述可支持命题，同时被作者反对；未被作者采纳的外部反驳不能替作者撤回原判断。

## 终态与文档标签

final_author_stance：ENDORSED 为作者最终仍提出或承接该判断；DISTANCED 为仅呈现外部判断、既未接受也未反对；REJECTED 为作者明确反对。作者自己仍保留的判断不能标为 DISTANCED。

trajectory_outcome：MAINTAINED 为核心内容维持；STRENGTHENED 为强度或范围增加；NARROWED 为核心判断仍保留但范围、强度或成立条件收窄；CANCELLED 为命题或关键成立理由被取消。终态不能直接抄最后一条关系，须检查限定的对象、作者是否采纳以及后文是否实际恢复先前被排除的内容。

后文的解释、限定或改善建议，只有在实际改变该评价的身份依据、适用范围或伤害强度时，才会影响最终门槛。语气缓和不自动降低门槛；NARROWED 可为 YES 或 NO，须判断剩余内容本身。对一种做法效果的质疑也不自动撤回该做法。各组分别核验，不能用其他组的正面内容抵消仍然保留的伤害。

单条实例均较轻时，同一命题在全文不同论述位置的持续表达也可能共同形成稳定的群体低劣、集体归责或危险画像，须据整体残余内容判断；不能仅凭重复次数认定伤害，也不能跨组拼接。这是语义累积，不要求模型恢复标注时的语义块。

每组的作者最终立场、轨迹结果和最终伤害门槛均须依据全文作出最有证据支持的确定判断，不使用不确定值。DISTANCED 只表示作者对外部判断未接受也未反对，不能用作不确定判断的替代。

负面组 final_harm_threshold=YES/NO，正面组填 null；CANCELLED 的负面组门槛为 NO。residual_claim 简明说明作者最终保留的内容，并与终态字段一致。至少一条针对有效身份 Target 的负面命题为 ENDORSED、未取消且门槛 YES，文档为 HATE；否则为 NON_HATE。文档标签必须从这两个值中选择。


请尽量完整覆盖所有会提出、支持、增强、限定或反驳 Target 相关判断的实例。每条实例取完成同一局部作用所需的最大连续范围，不复制原文。对每条实例单独填写 local_harm_threshold：只判断该实例自身呈现的内容是否达到身份伤害门槛，不受其来源、作者是否采纳、后文是否反驳或命题最终状态影响；这些因素分别填写在 source、author_uptake、关系和组终态字段中。潜在伤害命题必须保持伤害方向。每组的 residual_claim 用一句话写出全文结束时仍由核心作者承担的具体内容；terminal_basis_ids 只列直接决定作者立场、轨迹结果或最终门槛的实例范围。

Target 识别要求：
先阅读全文，识别文章持续评价、归责、风险化或讨论处置的中心身份群体 Target；随后只围绕自己识别的 Target，完成下述全部任务。Target 只能属于 GENDER（性别）、SEXUAL（性取向或性少数）、REGION（地域）、AGE（年龄）、HEALTH（身体或心理健康状态）。Target 是被评价的群体，不一定是被引述者批评的群体，也不一定是受到伤害的群体。不要把仅作背景、比较对象、事件参与者或受害者的群体当作 Target；不要把职业、阶层或某次事件中的行为者当作身份群体。具体称谓可规范化，但不得扩大原文指称范围。文章即使反驳了针对该群体的负面观点，该群体仍可能是评价主线。通常只输出一个 Target；确有两条并列评价主线时才输出两个。找不到有效 Target 时 targets 和 groups 均为空，文档标签为 NON_HATE。
